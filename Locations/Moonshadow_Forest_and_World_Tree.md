# 月影之森与世界树

> 「这条路今年封了。」  
> 「可我上个月还从这儿过。」  
> 「上个月它还没开始长。走西边，多绕两个时辰。……你要是四十年后再来，这条路又是通的。」

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 精灵族核心领地、移动聚落群与世界树根系 |
| 人口 | 约 43,000，分散在迁徙林社与树冠聚落 |
| 统治 | 月影议会与各林社 |
| 玩家阶段 | 中期大型区域、立体森林与世界树主线 |
| 核心矛盾 | 森林保存了大陆不愿记住的可能性，也因此被自己的记忆压垮 |

月影之森不是一片永远静止的原始树林。精灵会让住宅、道路和采集区随几十年周期迁移，避免地脉与精魂被单一用途耗尽。世界树位于森林的现实和可能层交界，它的根系不仅吸收水与魔力，也保留被世界熔炉切离的历史痕迹。

## 2. 玩家体验与地图节奏

外环强调听觉、风向和生态线索；中环引入移动道路与林社生活；内环进入政治、记忆与垂直树冠；世界树根境则把同一地点的不同历史叠在一起。

玩家不能只靠小地图直线前进。路标由叶片朝向、风铃节奏和精魂反应组成，但每条规则都会在安全区域教学并提供道具替代，避免“森林神秘”变成无提示迷路。

## 3. 地理、出入与季节

森林位于大陆西北地脉交汇处，外圈有天然河谷和人工活木界标。外来者需由林社、议会或拥有旧盟的羽灵担保。未经许可的传送会被导向外环缓冲地，而非直接杀死入侵者。

四季不是简单换色：春季道路生长、夏季树冠遮蔽增强、秋季记忆果成熟、冬季根境更容易显现。世界树异变后，局部季节会同时出现，形成战斗与解谜状态。

## 4. 居民、生计与日常

林社依靠果园、菌圃、药草、少量狩猎和与矮人工坊的金属交换生活。住宅由可拆木架、活枝和织叶构成，迁居是集体工程，不是施法瞬间让整座村庄行走。

普通精灵每天维护水渠、记录精魂、教育孩子和修复外环。长寿不代表生活缓慢：一场暴雨仍会在一夜冲垮桥，孩子也不会因为能活数百年便延迟到五十岁才学习承担家务。

死亡后，家属可选择把记忆片段交给忆席保存。是否保存、保存多久和谁能读取有严格同意仪式；世界树病变后，一些未同意的记忆开始自行出现，这是当地最严重的伦理危机。

## 6. 服务、经济与居住

外来冒险者可在外环林社休息、购买药剂、弓材和精魂媒介。交易更常使用公会币与劳动交换，不接受无许可大量购买活体材料。

高声望后玩家可获得季节居住枝屋，不拥有土地本身，而拥有一段迁徙周期内的使用与维护责任。枝屋会随林社搬迁，提供独特植物培育和精魂关系系统，不能当作免费传送到世界树核心的捷径。

## 7. 权力、防务与风险

月影议会通过活木结界、游侠、精魂契约和地形误导防守。主要风险包括帝国伐木队、无证采集、世界树记忆外溢、林社间资源争执，以及蚀理沿高度一致的共鸣传播。

森林强大但不全知。火灾、工业污染和破碎空间可能让精魂来不及回应；议会若继续封锁信息，外环居民会最先承担内环决定的代价。

## 8. 任务与状态变化

1. **〈不肯落地的叶子〉**：教学异常可能性如何影响日常。
2. **〈搬家的森林〉**：帮助林社迁移，玩家选择路线会改变后续商店和 NPC 邻里。
3. **〈树不记得那场雨〉**：恢复被删除年轮，决定知情范围。
4. **〈让世界树忘记一点〉**：分配哪些历史继续保存、哪些交还熔炉，改变根境和议会路线。

## 9. 美术、音频与关卡指令

- 区分“自然生长”和“被维护”：桥面有修枝切口，住宅有可拆接头，树干标记搬迁年份。
- 垂直地图以树冠光斑、风铃频率和世界树主干为锚，不依赖大量发光蘑菇。
- 音频使用风、木张力、远处劳动与不完整合唱；根境中同一旋律出现互相错开的多个版本。
- 不把整片森林固定为夜晚。月影之名来自夜间结界最强，不代表永昼阴暗。
