# 帝都・格兰赛尔与黑铁城塞

> 帝都《街衢条例》第十一条：主干道两侧不得设置遮蔽视线的摊棚、旗幡或临时棚屋，违者由巡城队当场拆除。  
> 城里的卖花人因此都练出同一个本事——把货担摆在随时能提起来就走的位置。

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 格拉西亚帝国首都、北陆军政与重工业中心 |
| 人口 | 约 310,000 |
| 地标 | 黑铁城塞、皇环大道、三塔军用校准阵 |
| 玩家阶段 | 中后期帝国政治、战争与大型工程区域 |
| 核心矛盾 | 高效秩序让庞大城市获得供暖和防护，也让监控、征收与命令同样高效 |

格兰赛尔建立在三座星塔覆盖的寒冷高原，城市由同心防区和放射大道组成。黑铁城塞位于北侧而非正中央，首先面对边境威胁；皇宫则处于内环，象征军队保护王权，但也给军务院独立权力。

## 2. 玩家体验与地图节奏

初到路线宽阔、清晰、守卫密集，几乎没有迷路空间。深入后，玩家会发现正式大道之外存在供热管廊、旧城巷和被扩建计划切断的社区。关卡在“国家设计的路线”与“居民实际使用的路线”之间切换。

## 3. 地理与出入

四座陆门、两条军用铁轨和三塔转运阵连接帝国。入城检查按军务等级分流，公会牌可缩短但不能免除。冬季暴雪时城门可能关闭，供暖配额成为比治安更重要的城市状态。

## 4. 居民、生计与日常

帝都依赖军工、矿业、行政、供暖和运输。工人区按班次生活，夜里也能听见锻炉；官僚区则围绕文书与考试。退伍者既享有优先住房，也常因旧伤和承诺未兑现形成抗议。

公共食堂、澡堂和识字课是帝国秩序真实提供的福利；户籍、征兵和非人族登记则使用同一套高效文书。生活的便利与控制不应分成两座城市，而在同一窗口发生。

## 5. 区域与兴趣点

| 区域 | 功能 | 内容 |
| --- | --- | --- |
| 皇环大道 | 仪式、阅兵、主干交通 | 公共事件、监控与追逐 |
| 黑铁城塞 | 军务院、黑魔军团、军械 | 战斗试炼、军令与前线 |
| 三塔区 | 能源、运输、星塔校准 | 战略选择与大型设施 |
| 炉工环 | 工厂、宿舍、供暖站 | 劳工、事故、密教渗透 |
| 旧城 | 市场、退伍者、异族社区 | 民间帝国与地下路线 |
| 文官环 | 学院、考试、档案 | 官僚调查、一律会 |
| 皇宫内环 | 皇帝、外交、国政 | 尤利西斯七世主线 |
| 北门纪墙 | 阵亡名单、边防出征 | 帝国牺牲的可见证据 |

## 6. 服务、经济与居住

军械、重甲、工程与大宗材料齐全，生活品受配给和季节影响。玩家可获得军方宿舍、旧城住宅或工程署工作间，不同选择改变接触人群与其他阵营观感。

## 7. 权力、防务与风险

皇帝、军务院、行省贵族和工程署分享权力。三塔阵让城市防护极强，也意味着任何控制校准的人都能决定交通、供暖和军队部署。

风险包括一律会渗透、军工事故、配给歧视、贵族私库、退伍承诺违约与三塔同时过载。玩家不能只击败一个邪教头目便解决帝国问题。

## 8. 任务与状态变化

1. **〈黑甲下面的人〉**：调查黑魔军团被指控的边境罪行。
2. **〈暖气先去哪里〉**：寒潮中在医院、工区和军械库间分配星塔热能。
3. **〈皇帝没有第二双眼睛〉**：清理渗透同时维持行政接替。
4. **〈笔直道路的岔口〉**：改革后开放社区议事与非人族军籍，地图新增合法横向通路。

## 9. 美术、音频与关卡指令

- 黑铁、灰石、暗红旗与蒸汽供暖构成视觉，不做纯粹邪恶尖塔。
- 同心大道利于导航，旧城与管廊提供非正式捷径。
- 音频以低铜管、步伐、锻炉和供暖管鸣响为主；居民区加入食堂与广播。
- 黑魔军团名称来自黑色魔导钢甲，甲胄设计不使用恶魔角与暗黑法师符号。
