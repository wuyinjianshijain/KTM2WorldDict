# 遥空庭院（Remote Sky Garden）

> 遥空庭院值班记录，星塔历 986 年冬：  
> 「第三区星幕亮度 0.94，已手动补正。七号构装仍不响应，第四次记录。温室的南瓜发芽了——写在这里没有用处，可今天只有这一条值得写。」

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 漂浮于星穹层内侧的观测岛、召唤站与世界熔炉权限节点 |
| 常住者 | 亚斯特拉・瑟怜、少量无人格维护构装 |
| 玩家阶段 | 序章、章节间世界枢纽、中后期熔炉入口 |
| 核心功能 | 世界地图、星塔状态、主线回顾、瑟怜关系、跨区支援配置 |
| 核心矛盾 | 它看似离世界最近，实际把守望者与所有生活隔开 |

遥空庭院不是普通天空城，也没有足以支撑居民社会的街区。它是星律民早期观测站在神代灾变后改造出的孤立设施，依靠星塔网维持位置。瑟怜被降格后与庭院权限绑定，离开超过短暂投影范围便会让世界熔炉失去活体校准。

## 2. 玩家体验与地图节奏

序章只开放落星台、云庭和瑟怜所在的观测廊，动线洁白、安静，玩家容易把这里理解为安全的神域。每推进一章，庭院会出现新的裂纹、关闭的门与从各地带回的小物，让“宏观设施”逐渐显露有人生活过的痕迹。

章节间回访遵循“先看世界变化，再处理个人关系，最后选择下一段路”的节奏。庭院功能不能全部集中在一张菜单：玩家需要走过变得不同的云庭，听见星塔负荷的声音，才会感到世界状态改变。

## 3. 空间、出入与限制

庭院不在固定地理坐标，而是沿星塔网最稳定的观测轨道缓慢移动。天空中偶尔看见的白色孤岛只是它投在现世的折影，常规飞行无法抵达。

玩家通过落星台召唤、已校准星塔或剧情投影返回。物资传送有质量限制，活物必须拥有庭院记录；这解释了为什么瑟怜不能把大批难民直接搬到天空避难。

边缘没有隐形空气墙。走出白石界线后，角色会进入低重力云海，并被归途纹路送回最近平台；熔炉失稳章节中归途纹可能短暂失效，形成真正危险。

## 4. 维护、日常与时间感

庭院没有自然昼夜，瑟怜用星幕亮度模拟时间。她在温室种植来自各地的耐性植物，不为食物供应，而是监测不同区域魔力是否还能支持正常生长。风信使每周带来物价、天气和灾情，玩家带回的普通物件会逐渐填满最初空白的住区。

维护构装只能执行固定工作：清洁、换晶片、搬运和重复警报。它们没有人格，不能替代瑟怜的社交。庭院曾有星律民观测团队，空房间与不同尺寸的工作台是他们离去或死亡的证据。

## 5. 核心区域与兴趣点

| 区域 | 初次开放 | 功能与叙事 |
| --- | --- | --- |
| **落星台** | 序章 | 玩家醒来处、返回点、召唤代价最初线索 |
| **云庭** | 序章 | 瑟怜日常、温室、同伴来访与关系事件 |
| **星图回廊** | 序章后 | 世界地图、区域异变、主线回顾 |
| **回声厅** | 第一章 | 保存从各地送回的声音与短讯，承担 NPC 世界反馈 |
| **旧观测员住区** | 第二章 | 星律民生活遗物、维斯珀与瑟怜过去 |
| **历算室** | 第三章 | 比较冲突时间线、选择破碎空间分支 |
| **无门阶梯** | 中期 | 通向不存在于普通空间的熔炉权限层 |
| **星炉前室** | 中后期 | 世界熔炉副本入口、权限分配与终局准备 |

## 6. 服务与成长

- 星图回廊显示已知路线、星塔状态和地区风险，不显示尚未调查的真相。
- 回声厅允许玩家选择优先接收哪个据点的求援，形成资源与时间取舍。
- 云庭可摆放关键旅程纪念物，装饰会触发同伴评论，但不做无限家具仓库。
- 完成星塔线后开放有限快速交通；目标必须是公共校准点，且魔力潮期间关闭。
- 瑟怜的支援能力在星炉前室配置，每次提高强度都会显示对应区域负荷。

## 7. 权限、风险与失效状态

庭院由瑟怜持有最高权限，玩家是被召唤协议承认的临时变量，伊维莉娜可通过观测室建立低权限连接。权限不是钥匙卡，而是“谁有权让哪条现实成为事实”的政治问题。

主要风险：

- 星塔同步偏差让房间位置改变，旧门通向错误记忆；
- 蚀理通过过度一致的观测报告渗入，所有构装开始给出同一答案；
- 熔炉过载时庭院会主动切断某个地区，以保护整体；
- 玩家定相加深后，召唤台可能把“返回原世界”识别为非法分支。

## 8. 故事落点

供玩家、剧情与同人创作取用的现成张力。它们都来自本词条已经写明的事实，不构成任务排期。

- **第一杯并不热的茶。** 一件生活小事就足以说明庭院不是全知神域，而是有人在值守的地方。
- **回声厅里少了一个人。** 某据点所有报告都正常，唯独没有人的闲谈——被格式化的灾难是这样被发现的。
- **观测员的空床。** 重建瑟怜团队的过去时会发现，维斯珀确实真诚照顾过成员。拒绝把他写扁。
- **把钥匙分出去。** 最高权限拆给城市、阵营还是个人，决定庭院之后是谁的地方。
- **庭院会随时间改变样子。** 从空白整洁到有生活痕迹，再在真相暴露后显得狭窄；若事情走向好的那一边，星幕恢复自然昼夜，瑟怜第一次不必亲自值守。
