# 世界熔炉（World Forge）

> **核心剧透**  
> 这里没有燃烧世界的火。所谓熔炉，是一座把无数“本来可以发生”熔成一个“已经发生”的选择机器。

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 位于可能层的现实修补设施、终局核心地下城 |
| 入口 | 遥空庭院星炉前室、少数主干星塔紧急权限门 |
| 建造者 | 瑟怜与神代末期多族工程者共同完成 |
| 玩家阶段 | 中期首次远观，后期多次进入，终局改造 |
| 核心矛盾 | 它每一次正确地救下眼前，都让未来少一个不同答案 |

世界熔炉没有稳定的现世体积。外观随观察者理解变化，但制作采用统一的“巨型历算工坊”语言：白色承重环、黑色空白面、像金属液一样流动的星图，以及由生活记忆组成的燃料光带。

## 2. 玩家体验与关卡节奏

第一次进入只到权限外环，玩家看见系统规模却无法理解输入。第二次进入“废案库”，发现被舍弃世界不是抽象数字。终局才进入核心，玩法从躲避自动校准、抢救分支，转为决定哪些权限交给谁。

关卡节奏为：

1. 读取当区现实问题；
2. 比较系统提出的稳定解；
3. 进入被排除的两至三个分支寻找代价；
4. 带回无法被熔炉自动处理的证据；
5. 让受影响阵营参与定相。

## 3. 空间与出入

熔炉位于星穹层和可能层之间，不能靠普通传送抵达。进入者必须拥有瑟怜权限、主干星塔签名或玩家的界外因果。队伍人数越多，系统需要保持的现实连续性越复杂，因此大型军队无法直接攻入。

离开依赖“返还记录”：系统确认进入者仍与出发时是同一连续个体。余忆过多、携带超额定相物或被蚀理重写者可能无法通过，需要同伴用共同经历证明身份。

## 4. 运转与“日常”

熔炉没有居民，但保存着建造者留下的工作痕迹：不同语言的标记、磨损工具、用于轮班的茶炉和从未发出的撤离通知。这些细节必须证明设施由具体的人在灾难中建成，而不是瑟怜挥手创造。

自动构装持续比较星塔报告、修补小型矛盾并把无法采用的分支送入废案库。高负荷时，它会优先保护人口、星塔和既有历史，边境、少数群体与尚未登记的新事物更容易被舍弃。这不是系统拥有偏见人格，而是千年前紧急规则从未接受当代修订。

## 5. 核心区域与机关

| 区域 | 功能 | 玩法 |
| --- | --- | --- |
| 权限外环 | 识别进入者、分配观察权限 | 身份、队伍关系与记忆校验 |
| 历算廊 | 展示当前现实与稳定解 | 多版本场景比较 |
| 废案库 | 保存被舍弃可能性 | 地下城分支、NPC 伦理 |
| 回火渠 | 把定相物与记忆送回现世 | 战利品容量与撤离压力 |
| 旧工坊 | 建造者工具、星律民记录 | 瑟怜历史、制作解谜 |
| 校准砧 | 局部修改修补优先级 | 阵营权限、地区状态 |
| 唯一解核心 | 熔炉主判断环 | 蚀理战、终局制度改造 |

机关不以转动普通齿轮为主。玩家需要让互相冲突的证词同时保持、故意保留一处不稳定、或让两个阵营共同授权，才能打开只接受“唯一正确签名”的门。

## 6. 奖励与长期功能

熔炉不掉落常规金币和量产装备。奖励包括：

- 地区规则调整，例如降低某类破碎空间形成率；
- 星塔权限与支援配置；
- 保留下来的分支 NPC、技术或记忆；
- 角色终极能力的伦理许可与系统上限；
- “未采用方案”档案，影响新游戏周目或后续章节。

终局后若改造成分布式系统，世界地图会显示多地议决与负荷，不再由瑟怜一人提供全部支援。

## 7. 防务、风险与失败

熔炉的“敌人”主要是自动修正：

- 重复走廊把队伍送回系统认为正确的路线；
- 被删去的队友行动从机关记录中消失；
- 构装体以最低伤害方式强制撤离“异常变量”；
- 蚀理使所有 NPC 逐渐说出同一套合理答案。

失败不只等于死亡。玩家可能带着错误但稳定的结局返回，让某个地区从此失去另一个选择；系统必须清楚记录并在世界表现，避免无提示永久惩罚。

## 8. 主线任务与状态变化

1. **〈门只承认一个人〉**：玩家第一次用共同记忆替同伴通过返还记录。
2. **〈废案里有人生活〉**：确认破碎空间居民的伦理地位。
3. **〈千年前的紧急条款〉**：找到多族工程者原本计划在灾后修订、却从未执行的规则。
4. **〈把未来分给今天〉**：终局在集中熔炉、关闭、分布式改造之间完成更具体的第三方案。

## 9. 美术、音频与关卡指令

- 避免传统岩浆铁砧。火焰只作为“选择被定相”的短暂白热边缘。
- 巨型结构与生活遗物同场：一条星轨旁放着轮班杯，宏观代价才会落到人。
- 音频从多条不同拍号的旋律逐步收束为单一节拍；玩家保留分支时，失去的声部重新出现。
- UI 与场景文字必须清楚区分“推荐稳定解”和“唯一允许解”，让玩家察觉系统语言的政治性。
