# 破碎空间门与公会前站

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 围绕稳定破碎空间入口建设的登记、救援与定相设施 |
| 管理 | 冒险者公会为主，地方政权与时钟塔协作 |
| 玩家阶段 | 全阶段地下城准备、撤离与战利品结算 |
| 核心矛盾 | 前站把未知变成可工作的风险，也容易让人误以为所有损失都能写进表格 |

“地下城门口的营地”在成熟地区会发展成高度专业的前站。它不仅卖药和存档，还负责确认进入者身份、预计闭合时间、救援资源、战利品定相和失踪者物品归还。

## 2. 玩家体验与流程

标准探索循环：

1. 在登记厅选择目标、风险和撤离条件；
2. 留下魔力签名或血样；
3. 在红线门廊检查装备与定相容量；
4. 进入破碎空间；
5. 从回归厅返回并接受连续性问答；
6. 鉴定战利品、结算任务和处理余忆。

新手前站流程完整、节奏缓慢；高阶玩家可预设模板，但不能跳过身份与容量警告。

## 3. 入口类型与选址

| 入口 | 特征 | 前站设计 |
| --- | --- | --- |
| 固定门 | 长期稳定、可重复探索 | 永久建筑、市场、完整救援 |
| 潮汐门 | 按魔力潮开启 | 可拆营地、倒计时与拥堵 |
| 漂移门 | 入口在地区内移动 | 侦测塔、车载前站 |
| 事件门 | 因具体历史或人物出现 | 临时封锁、剧情优先 |
| 海床 / 高空门 | 特殊环境 | 鱼人族、羽灵与专用回归设施 |

前站不能建在入口正前方，以免空间扩张直接吞没设施。标准安全距离由时钟塔鉴定，地形不足时使用可抛弃式外廊。

## 4. 工作人员与日常

前站职员包括登记员、风险官、救援队、定相师、医护、仓库员、炊事员和归还官。许多人曾是因伤退役的冒险者，熟悉“队伍说还能继续”时真正意味着什么。

入口稳定期，前站像轮班矿区；闭合期则突然空下来，只剩守门与等待失踪者的家属。旅店不会立刻清理逾期房间，归还官在七日、三十日和确认闭合三个节点分别联系家属。

## 5. 标准区域与兴趣点

| 区域 | 功能 | 玩法 |
| --- | --- | --- |
| 委托厅 | 风险、队伍、合同 | 地下城选择与匹配 |
| 签名室 | 连续性样本 | 身份剧情、复制者疑云 |
| 红线门廊 | 装备、容量、倒计时 | 准备与明确警告 |
| 回归厅 | 撤离、问答、急救 | 余忆、队友确认 |
| 定相仓 | 战利品稳定与隔离 | 容量取舍、经济 |
| 救援塔 | 回归点、绳索与信号 | 失败保护、限时救援 |
| 归还墙 | 失踪者名牌与物品 | 长期 NPC、纪念与任务 |
| 前站食堂 | 低价高热量饮食 | 队伍日常、情报 |

## 6. 服务、经济与居住

基础登记费包含救援储备，公会委托通常已代扣。私人探索需购买风险套餐，不允许只付最低费用却要求最高级救援。

前站商店价格随入口状态上涨，但基础水、绷带和撤离标记受公会限价。长期稳定门会吸引商人和家属形成聚落；若入口闭合，玩家可参与转型为矿镇、研究站或纪念地，避免所有 NPC 功能凭空消失。

## 7. 权力、防务与风险

公会负责职业规则，地方政权控制武装与土地，时钟塔决定定相安全。三方常为“继续开放能获得资源，关闭能降低外溢”争执。

主要风险：

- 入口扩张吞没红线；
- 回归者携带未识别版本或自复制物；
- 定相仓被走私者盗用；
- 高阶队伍占用全部救援资源；
- 委托人隐瞒空间最坏分支。

## 8. 故事落点

供玩家、剧情与同人创作取用的现成张力。它们都来自本词条已经写明的事实，不构成任务排期。

- **回来的是第几个人。** 两名拥有相同签名与相同记忆的队员同时返回，前站的规章对此完全没有准备。
- **未归者也应结算。** 委托人拒绝支付失踪队伍已经完成的调查，而公会的追责条款是写给活人的。
- **红线向前走了一步。** 入口扩张时，撤离、抢救定相仓与保持门开启三者只能选两样。
- **门关上以后。** 失去主要经济来源的前站要不要变成一座真正的聚落，取决于留下来的人还剩多少钱和多少力气。
