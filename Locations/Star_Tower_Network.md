# 星塔网（Star Tower Network）

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 覆盖大陆的魔力观测、现实校准、通讯与有限交通网络 |
| 数量 | 7 座主干塔、约 60 座地区塔、数百个小型观测柱 |
| 管理 | 地方政权、时钟塔、教廷与公会按地区共管 |
| 玩家阶段 | 全阶段区域解锁与世界状态系统 |
| 核心矛盾 | 星塔让城市安全而互联，也让中心地区能把风险转移到看不见的边境 |

星塔外观因地方材料不同，却共享一套可辨认结构：三足承台、贯穿塔身的校准井、朝向星穹的开口环与面向居民的钟 / 灯信号。它首先是基础设施，传送只是高负荷衍生功能。

## 2. 玩家体验与地图节奏

每个大区域的星塔任务包括“找到异常 → 恢复局部服务 → 决定负荷 → 看见地区代价”。修塔不是重复爬塔开地图；不同地区的问题来自供水、军用优先、记忆外溢、维护垄断或居民反对。

玩家首次接触的是澄晶镇外的小型地区塔，只能提供预警和归路晶标。万花筒介绍标准与校准，帝都展示军事化，月影之森则让玩家看见星塔与活体地脉冲突。

## 3. 标准结构

| 模块 | 功能 | 关卡用途 |
| --- | --- | --- |
| 承台与地脉室 | 把塔固定在本地魔力循环 | 地下维护、环境谜题 |
| 校准井 | 传递数据与魔力，贯穿全塔 | 垂直导航、危险轴 |
| 观测环 | 读取星穹与现实偏差 | 天文机关、远景平台 |
| 信号层 | 钟、灯、传信晶体 | 城镇状态、通讯任务 |
| 转移台 | 有限质量的公共交通 | 快速移动、优先级冲突 |
| 熔炉权限龛 | 紧急连接世界熔炉 | 后期主线、严格访问 |
| 维护住区 | 工人、备件、厨房与值班床 | 让设施拥有真实劳动 |

## 4. 维护者与普通生活

塔工包括测量员、地脉师、清井工、传信员、守卫和负责向居民解释警报的地方联络员。主干塔采用三班轮值，地区塔常因预算只有一班半人手，事故因此不是总由阴谋造成。

星塔影响附近生活：

- 传信与魔导灯更便宜；
- 农户依据塔钟安排防灾与播种；
- 房价在稳定覆盖区更高；
- 负荷上升会造成失眠、余忆与精魂迁徙；
- 停塔后旧式手艺与人工信使重新变得重要。

## 5. 塔型与代表节点

| 塔型 | 代表 | 特点 |
| --- | --- | --- |
| 主干观测塔 | 万花筒时钟塔协同节点 | 标准最完整、学术访问 |
| 军用主干塔 | 格兰赛尔三塔阵 | 高防护、交通优先、风险外推 |
| 活体兼容塔 | 月影之森外环塔 | 与树根共生，效率低但生态损害小 |
| 圣疗塔 | 奥蕾利亚上层塔 | 过滤生命术污染、服务医院 |
| 裂域重锚 | 黯渊旧星塔 | 供水与重力稳定，严重破损 |
| 地区预警塔 | 澄晶河谷塔 | 魔物潮与破碎空间预警 |
| 废弃塔 | 各地遗迹 | 地下城入口、走私与异变源 |

## 6. 服务、经济与玩家成长

塔况决定传信、交通、魔导器服务和地区价格。玩家修复后可解锁：

- 区域异常预览；
- 有冷却与费用的公共快速交通；
- 住宅归路晶标；
- 远程接收紧急委托；
- 星塔工坊与地区支援配置。

玩家不能永久占有公共塔。高声望提供参与负荷决策的席位，使用便利同时需要承担维护、优先级和边境外溢的政治责任。

## 7. 权力、防务与风险

塔权限分为维护、交通、观测、军用与熔炉五级。任何机构同时掌握三项以上便构成地区政治危机。紧急情况下地方长官可提高负荷 48 小时，延长需要议会、公会或时钟塔复核。

风险包括地脉过抽、权限伪造、观测报告同质化、传送事故、军用征收和把负荷外推到没有代表权的地区。

## 8. 任务与状态变化

每座关键塔至少有三个状态：

| 状态 | 世界表现 | 玩家效果 |
| --- | --- | --- |
| 稳定 | 钟声清楚、灯光连续、精魂路线正常 | 完整交通与服务 |
| 高负荷 | 极光、井水异味、居民失眠 | 支援增强，异常与物价风险上升 |
| 停运 | 人工信使、黑暗街区、旧手艺复苏 | 无快速交通，部分生态恢复 |
| 分布式 | 地方共同签名、负荷公开 | 效率略低，风险更均衡、任务更多 |

## 9. 美术、音频与关卡指令

- 保留共同轮廓与模块，让玩家远处认出星塔；材质与装饰体现地区。
- 维护住区必须存在，避免塔只有机关没有工作人员。
- 稳定钟声由多音组成，高负荷时逐渐只剩单一音高，呼应蚀理主题。
- 快速交通 UI 显示费用、负荷与不可用原因，不把公共基础设施做成无条件传送菜单。
