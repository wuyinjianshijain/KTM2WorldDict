# 地点总览

厄达斯的地点按玩家用途分为四类：能够建立日常关系的**聚落**、决定区域权力的**城市与要塞**、维持世界法则的**战略设施**，以及由被舍弃的可能性形成的**破碎空间**。地点词条不只描述风景，也规定出入、生活、服务、风险、地图节奏与剧情状态变化。

## 4. 地点共通设计规则

- 一座“安全城镇”必须说明谁在巡逻、如何供水、夜间如何通行，以及安全何时会失效。
- 每个常驻据点至少提供休息、补给、装备维护、任务、仓储、治疗和一条能形成长期记忆的生活路线。
- 中后期回访不能只为数值服务。旧 NPC 的工作、店面、家庭和政治态度会随主线发生可见变化。
- 战略设施必须同时留下宏观作用和普通人可感知的痕迹，例如夜空颜色、井水味道、物价或迁徙。
