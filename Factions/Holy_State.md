# 天圣国与圣教廷

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 政体 | 教皇、枢机院与修会共同治理的神权国家 |
| 统治者 | 教皇拜亚斯三世 |
| 精神象征 | 大圣女克菈丽娅 |
| 核心资源 | 大陆最大的医院、解咒网络、朝圣路与文书教育 |
| 核心矛盾 | 它真正救治了无数人，也用“谁值得被救”维持教义与政治边界 |

## 2. 对外主张

教廷宣称世间苦难源于人与世界背离圣光的“原罪”，净化、服侍与秩序能让灵魂重新回到光中。圣光并非完全虚构：教廷历代确实保存了最成熟的治愈、净化与灾后照护体系。许多普通信徒信仰它，不是因为无知，而是因为在最绝望的时候真的有人从教堂里端来药和热水。

问题在于，神代后的政治叙事把魔族与暗属性逐步等同于原罪，使医疗制度和排异制度在同一套文书中成长。

## 3. 历史与现实利益

天圣国始于战后神官营地。早期修士记录伤员姓名、隔离魔力疫病并建立跨地救护路线，逐渐获得比地方领主更高的信任。星塔历 173 年，各大修会拥立首任教皇，建立天圣国。

现任教皇拜亚斯三世擅长行政和妥协。他并非秘密信奉黑暗的简单反派，而是坚信一旦承认《圣明纪》的根基有误，医院捐赠、朝圣秩序与各国特许都会一起崩塌。因此他选择掩盖证据、牺牲异端，以保住自己认为更重要的多数人。

## 4. 组织、资源与普通成员

- **教皇厅**：掌握教义解释、外交和最高任命。
- **枢机院**：管理地区教区、财产与医院预算。
- **白纱修会**：护士、医师、药师与灾后救援者，民间声誉最高。
- **明鉴庭**：调查诅咒、禁术和异端，拥有拘押权，内部最易走向滥权。
- **巡礼署**：维护道路、食舍和身份文书，实际上是庞大的信息网络。

基层神职人员的日常是洗绷带、抄病历、调解家庭纠纷和为无名死者登记。大多数人从未参与异端审判，却会因为服从预算和转介规则，在不自知中延续对魔族与暗术士的排斥。

## 5. 内部分歧

- **守灯派**认为教义可以修订，救人制度才是信仰核心；克菈丽娅逐渐成为其公开旗帜。
- **纯光派**把任何妥协视为污染，主张扩大明鉴庭权力。
- **安序派**以拜亚斯三世为中心，知道部分历史有误，但认为真相必须被政治管理。
- 白纱修会最现实的问题是人员不足：他们支持改革，却害怕大规模分裂让边境医院立刻停摆。

## 6. 克菈丽娅与治愈权力

克菈丽娅的治愈能精确调度生命力，远超普通圣职者。她不是“光之女神转世”，教廷却有意维持这种暧昧，以巩固信徒信心。她公开配合，是因为名望能为医院争取预算；私下反抗，是因为同一名望也被用来为审判背书。

她的核心选择不是简单摧毁或接管教廷，而是如何在不让医疗网络首先崩溃的情况下，终止“救治资格由信仰纯度决定”的制度。

## 7. 对外关系

天圣国与帝国互换军医和保护，与兰维里斯共享朝圣路，与时钟塔在医学研究和灵魂伦理上长期冲突。月影议会允许白纱修会交换药材，却拒绝明鉴庭入境。黯渊王庭把教廷视为千年迫害的制度核心，双方公开接触极少。

瑟怜的存在若被公开，不会简单证明教廷正确或错误：她不是教义中的创世女神，却真实完成过被后人称作神迹的拯救。

## 8. 玩家声望与任务

- 救灾、保护病患隐私、完成高风险净化会提升基层信任。
- 支持守灯、纯光或安序路线影响医院、审判与公开历史。
- 高声望解锁治疗、解咒、文书通行与封印书库，也会让玩家被要求为教廷公开站台。

关键任务：

1. **〈空着的第七张床〉**：医院有药却因身份规则拒绝一名魔族儿童，玩家的解决方式会影响整套转介制度。
2. **〈圣女没有显灵〉**：克菈丽娅无法同时救两个灾区，教廷要求伪造她的神迹记录维持秩序。
3. **〈初稿的灰烬〉**：找到《圣明纪》删改页后，必须先建立替代叙事与医疗预算联盟，才能公开而不只引发崩塌。

## 9. 制作备注

- 教廷视觉以乳白石、暖金、蜂蜡灯和大量洗涤痕迹为主；医院应有真实劳动感。
- 纯光派不能垄断所有信徒形象，守灯派也不能自动代表现代正确答案。
- 角色关联见[克菈丽娅](../Characters/Claria_Luminaria.md)。
