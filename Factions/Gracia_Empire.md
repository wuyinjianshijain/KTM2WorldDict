# 格拉西亚帝国

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 政体 | 皇帝、军务院与封地贵族并存的中央集权帝国 |
| 统治者 | 尤利西斯七世 |
| 核心资源 | 北陆粮区、铁矿、最大常备军、三座主干星塔 |
| 军事象征 | 黑魔军团 |
| 核心矛盾 | 帝国确实挡住最多边境灾害，也借此要求所有人服从它定义的秩序 |

## 2. 对外主张

帝国的国策是“城墙之内，先有秩序，才有明日”。在北境居民眼中，这不只是宣传：帝国军每年都有人死在魔物潮与裂域前线。问题在于，中央把“保护人类”逐渐扩大为“只有帝国能够定义何为人类利益”。

对非人族的官方政策是登记、利用与监控。拥有军籍、纳税记录或技术价值者可以获得有限晋升，但很难进入决定政策的核心。地方差异明显，边境军镇往往比首都贵族更愿意与异族合作。

## 3. 历史与现实利益

帝国由神代后的人类军镇联盟扩张而来。统一结束了长期领主混战，也把军功家族变成新的贵族。当前繁荣依赖北陆矿产、征服地粮税与星塔交通；一旦星塔负荷下降，横跨大陆的军队与征税体系都会迅速失灵。

尤利西斯七世并非昏庸暴君。他知道贵族腐化与某个信奉“唯一秩序”的密教正在渗透官僚，却担心大规模清洗会先摧毁正在守边的行政体系。这种谨慎为改革争取时间，也给渗透者继续扩张的空间。

## 4. 组织与资源

- **皇廷**：制定法令、外交与高级任命。
- **军务院**：控制常备军、军粮与星塔军用时段，实际权力仅次于皇帝。
- **行省总督**：在税收、治安和征兵上拥有广泛权力，是腐败与地方改革同时发生的层级。
- **黑魔军团**：身穿黑色魔导钢甲的近战精锐，名称来自装甲材质，不是魔族军团，也不以暗魔法为主。
- **帝国工程署**：维护道路、堡垒和星塔，是最容易与时钟塔学者发生冲突的技术官僚。

普通士兵的生活由长途行军、装备保养、识字课和轮休构成。帝国军饷稳定，吸引贫困青年；退伍后的土地承诺却常被地方贵族拖欠。

## 5. 内部分歧

- **铁序派**要求军务院直接接管星塔与公会，认为危机时期没有协商余地。
- **新法派**主张统一税法、开放非人族军籍，并削减贵族私兵。
- **封地派**维护地方特权，常以传统和边防成本阻挠中央改革。
- **一律会**是渗透官僚的密教，受蚀理思想影响，坚信世界只有在所有人遵循同一答案时才能得救。成员仍要为主动参与负责。

## 6. 对外关系

帝国与天圣国互相需要：教廷提供军医与合法性，帝国保护朝圣路；双方也争夺对星塔的解释权。兰维里斯是贸易伙伴和潜在附庸。月影议会拒绝帝国伐木队进入边界，冲突周期性爆发。黯渊王庭是长期敌手，但一线军官比首都更清楚双方有时面对同一批魔物。

## 7. 玩家声望与任务

- 协助疏散、遵守军令和带回前线证据会提升军方信任。
- 支持新法、铁序或地方自治改变政治立场，不由单一“帝国好感”覆盖。
- 玩家可获得军用交通、工程制造与黑魔军团训练，也可能因此被其他势力视作帝国代理人。

关键任务：

1. **〈黑甲下面的人〉**：调查一支被指控屠村的黑魔小队，发现军令、伪装者与士兵自行报复三种责任同时存在。
2. **〈粮车先过哪座桥〉**：星塔停运后，军粮与难民只能选一方先行，选择改变前线和城市物价。
3. **〈皇帝没有第二双眼睛〉**：玩家向尤利西斯提交一律会证据，同时必须说明由谁接替被捕官员的工作。

## 8. 制作备注

- 帝国视觉以黑铁、白灰石、深红军旗和大量维护编号为主；腐败通过修缮差异和特权通道表现，不靠到处堆骷髅。
- 黑魔军团的“黑魔”固定解释为黑色魔导钢，避免本地化误写为恶魔军。
- 现任皇帝姓名保持尤利西斯七世（Ulysses VII）。
