# 冒险者公会

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 跨国职业登记、委托担保、救援与战利品鉴定组织 |
| 总部 | 无单一首都；最高协调机构为“七灯议席” |
| 主要资源 | 支部网络、风险档案、担保金、回归点与定相鉴定 |
| 玩家关系 | 最早接触的长期系统阵营 |
| 核心矛盾 | 为保护冒险者制定的制度，也能成为地方政权外包风险与责任的工具 |

公会的英雄故事很多，真正让它存在至今的却是枯燥文书：谁雇了人、风险有没有说清、失踪后要找几天、带回来的东西属于谁。它不把冒险当成浪漫职业，而是承认总有人会走进危险，因此至少让那些人有名字、有合同，也有人等他们回来。

## 2. 对外主张

公会徽记上的七盏灯分别代表登记、报酬、证据、救援、归还、仲裁和记名。支部大厅通常刻着同一句话：“未归者也应结算。”这是公会区别于私人佣兵团的核心承诺。

公会宣称政治中立，但只在职业规则上中立：它不会替雇主决定战争正义，却有权拒绝以讨伐名义发布屠杀平民、抓捕逃奴或掠夺合法聚落的任务。

## 3. 历史与现实利益

神代结束后的难民时代，大量武装者靠清理遗迹与护送粮队谋生。最早七个大型营地互认任务铜牌、失踪名单与伤残抚恤，形成“七灯盟约”。国家恢复后多次试图收编公会，却离不开它对破碎空间、魔物材料和跨境队伍的知识。

公会今日最重要的利益不是抽成，而是**通行权**。只要各国承认公会牌，支部就能调动人员、送回遗体、追查失踪队伍并在灾害时跨境救援。任何一国试图把公会完全军队化，都会威胁整个网络。

## 4. 组织、资源与日常

七灯议席由七个区域席位组成，负责评级标准、跨国制裁与救援基金。地方支部长拥有很大自治权，支部规模从一间柜台到拥有诊疗所、仓库和训练场的完整设施不等。

普通职员包括任务审查员、接待员、地图员、鉴定师、遗物保管员、救援队和负责通知家属的归还官。后者很少出现在英雄故事里，却是公会内部最受尊敬也最容易离职的职位。

冒险者评级为 F、E、D、C、B、A、S。评级衡量可被委托的风险上限，不是人格、贵族头衔或绝对战斗力。晋级需要任务记录、队友评价、急救与撤退判断；只会击杀强敌的人可能长期无法晋级。

## 5. 内部分歧

- **灯守派**坚持高额救援储备、风险披露和任务拒绝权，愿意得罪国家与大商会。
- **开路派**认为边境支部必须更灵活，过度审查只会把工作推向地下佣兵市场。
- **承包派**主张接受国家长期军务，以换取稳定预算和合法武装。
- 普通冒险者最关心的是受伤能否报销、失败是否还能吃饭，以及高阶队伍是否抢走所有好任务。

## 6. 对外关系

公会与兰维里斯合作最顺畅，澄晶前哨镇即由镇议会、王国与公会三方治理。帝国允许公会活动，但要求边境任务接受军方审查。天圣国提供治疗人员，同时拒绝为部分暗术使用者服务。时钟塔负责高阶定相标准，双方会为昂贵鉴定费争执。

黯渊王庭的公会资格仍未被多数人类国家承认，导致魔族冒险者跨境后常被降级或重新审查。这是玩家可以推动的制度改革线。

## 7. 玩家声望与内容钩子

- **信任提升**：如实报告失败、带回失踪者线索、优先救人、保护委托证据。
- **立场选择**：支持更严格保障、边境自治、国家承包或魔族资格互认。
- **债务事件**：调用公会救援、损坏回归点、让支部为玩家的政治选择承担罚款。

关键任务：

1. **〈名字没有回来〉**：一支队伍全员失踪，委托人只愿支付“成功报酬”。玩家需要证明调查本身已经完成，并决定是否公开委托人隐瞒的风险。
2. **〈第八盏灯〉**：魔族支部申请加入跨国网络，七灯议席要求玩家作为无国籍见证人审查其制度。
3. **〈英雄不在免责条款里〉**：S 级队伍造成城镇损失，公会是否会因其名望降低赔偿成为公开危机。

## 8. 制作备注

- 任务 UI 必须显示风险来源、预付、失败结算、附加目标与救援条款。
- 公会不是无穷任务生成器。公告板内容随季节、地区状态和居民生活变化。
