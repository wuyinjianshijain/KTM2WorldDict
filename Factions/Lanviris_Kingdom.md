# 兰维里斯王国

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 政体 | 王室与十二誓约领组成的有限王权 |
| 统治者 | 阿尔德伦四世 |
| 核心资源 | 东西商路、河谷粮食、边境骑士与开放港口 |
| 军事象征 | 白蔷薇骑士团 |
| 核心矛盾 | 王国以誓约限制王权，也让旧贵族能把私利包装成地方自治 |

兰维里斯没有帝国的兵力，也没有天圣国的信徒网络。它能维持独立，靠的是让商队、异族工匠、公会与地方领主都觉得“这条路继续畅通”比吞并彼此更划算。

## 2. 对外主张

王国的公共信条是“誓约约束持剑之人”。法律强调契约、通行权与地方议会，允许不同信仰和族群建立社区。外来者因此更容易落脚，但自由并不平均：拥有土地与古老誓约解释权的贵族仍能让普通人花数年争取一次审理。

## 3. 历史与现实利益

星塔历 701 年，十二个互相征战的河谷领主在魔物潮中签订白蔷薇盟约，把最精锐骑士交给共同指挥。王国由防务合同而非单一征服形成，王室权力来自主持誓约与商路仲裁。

王国今日收入依赖关税、粮食和冒险者消费。澄晶河谷等前哨镇承担破碎空间带来的危险，也让内地获得魔石和稀有材料。中央若只拿走收益、不补充守备，盟约本身就会失去正当性。

## 4. 组织、资源与日常

- **王室议政厅**：国王、十二领代表、商路席与公会观察员共同议政。
- **白蔷薇骑士团**：直属盟约而非国王个人，负责跨领边防与贵族违法调查。
- **河路署**：维护桥梁、关卡和驿站，是王国真正维系统一的行政核心。
- **城镇议会**：拥有治安、市场和地方工程权，规模较大的边境镇能与领主谈判税额。

普通居民习惯把政治理解为道路：哪座桥修了、哪段夜路有人巡、今年通行税涨了多少。王国节庆常以重新宣读地方誓约开始，孩子会在学校练习辨认不同领地印章，以免被假税吏欺骗。

## 5. 内部分歧

- **续誓派**支持国王逐步统一法律和预算，避免贵族利用条文漏洞。
- **领权派**担心中央改革变成帝国式集权，拒绝交出私兵与税权。
- **开路派**由商人、公会和边境镇组成，主张给稳定纳税的异族与外来者更快的居住权。
- 部分白蔷薇骑士认为团长塞西莉亚调查贵族已越过军职，另一些人则认为这正是誓约存在的理由。

## 6. 对外关系

兰维里斯与格拉西亚既贸易又提防被经济控制；与时钟塔合作制定魔导商品标准；与天圣国共享医院和朝圣路，但拒绝把异端审判权交给教廷。王国对魔族没有正式建交，边境却存在长期秘密交换粮食与矿石的路线。

## 7. 玩家声望与任务

- 信任来自保护道路、履行合同和愿意接受仲裁。
- 支持王权统一、地方自治或开放居住权会改变具体领地反应。
- 高声望解锁住房、商路折扣、骑士训练和地方议会投票代理，但也意味着玩家要为担保对象承担债务。

关键任务：

1. **〈白蔷薇不替谁开花〉**：一名领主要求骑士团镇压拒缴灾年税的村庄，玩家需解释誓约究竟保护秩序还是居民。
2. **〈桥的两边都是王国〉**：两个领地都声称没有预算修桥，玩家投资、仲裁或公开账目会形成不同长期商路。
3. **〈泽菲利斯旧案〉**：塞西莉亚父亲的罪名牵涉王室稳定，翻案必须同时处理真正受害者与现任官员。

## 8. 制作备注

- 王国视觉以银白、钴蓝、木石混构与蔷薇结绳为主；不同领地保留旗帜和甲胄差异。
- [澄晶前哨镇](../Locations/Lucentrystel_Outpost.md)是王国制度的前期落点。
- [塞西莉亚](../Characters/Cecilia_Zephyris.md)忠于的是誓约中的人，而不是国王个人；角色线不能简化为“发现国家腐败后离开”。
