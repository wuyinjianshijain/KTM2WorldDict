# 寂无盟约

## 1. 词条摘要

| 项目 | 定稿 |
| --- | --- |
| 性质 | 监测并处置法则异常、失控禁术与星塔级威胁的秘密网络 |
| 公开状态 | 多数国家否认其存在 |
| 最高外勤位阶 | 零律执行官 |
| 代表人物 | 希尔瓦琳・奥瑞丝 |
| 核心矛盾 | 有些灾难必须在公众理解前阻止，但无人监督的必要秘密会很快学会把异议称为灾难 |

## 2. 对外主张与实际方法

盟约没有公开宣言。成员入会时只抄写一句话：“当术式使证据本身失效，先让术式停止。”它处理常规法庭无法审理的目标：会重写证人记忆的咒法、持续自我复制的术式、让一座城同时出现两段历史的星塔事故。

方法包括封印、撤离、切断媒介、伪造无害事故解释，以及在没有其他选择时处决施术者。最危险的不是杀人命令，而是组织逐渐把“省去解释”当成效率。

## 3. 历史与现实利益

盟约前身由神代后数名星塔维护者和事故幸存者建立。他们发现部分异常会在被广泛描述后扩散，于是采用分散档案、单向联络与最少知情原则。星塔历 859 年，希尔瓦琳在白冠之乱后被盟约接触，以掌握零律的代价换取压制世界树侵蚀的方法。

盟约没有领土和公开预算，依靠被隐藏的国家拨款、时钟塔旧账户与成员合法身份维持。秘密让它免受政治直接控制，也让高层命令越来越难被核验。

## 4. 组织、资源与成员生活

- **听默者**：从事故、学术和情报渠道识别异常。
- **封缄师**：制作隔离、记忆保护与反术式媒介。
- **归零员**：现场撤离、关闭与证据回收。
- **零律执行官**：能在短时间切断目标与常规法则联系的极少数外勤者。
- **无声席**：通过匿名、多重签名发布高风险命令，成员彼此不完全知道身份。

普通成员拥有医生、抄写员、守卫或学者的公开工作。他们最常做的是确认“什么都没有发生”，随后独自保存不能向家人解释的记忆。盟约提供心理隔离训练，却把长期情感迟钝误认为职业成熟。

## 5. 内部分歧与渗透

- **封缄派**坚持最低伤害和可逆处置，哪怕增加暴露风险。
- **归零派**认为任何异常都应在形成社会影响前彻底抹除。
- **证言派**主张建立外部监督者，让至少一个不受盟约控制的人保存完整记录。

无声席的部分决策已表现出蚀理特征：命令口径过度一致、替代方案从档案中消失、质疑者被自动归类为污染。尚不能确认是成员主动采用、长期接触导致，还是维斯珀通过旧星塔协议影响。无论来源，执行者仍需为可避免的伤害负责。

## 6. 希尔瓦琳的位置

希尔瓦琳不是没有意志的杀人工具。她接受盟约，是因为当时只有零律能阻止世界树侵蚀扩散；她继续执行，是因为相信由自己承担罪名能减少更多人受伤。无声席利用了这种责任感，把缺少证据的命令包装成“只有你能做”。

她的角色线不是恢复情感后退出组织那么简单，而是建立一种让真正危险的秘密仍能被监督、申诉与复核的制度。

## 7. 对外关系

盟约借用时钟塔的观测数据，却不接受学席直接指挥；与冒险者公会共享撤离和失踪记录，但会隐去异常原理；天圣国部分审判官把盟约视作不受神学约束的私刑组织，边境医院则曾依赖其封锁魔力疫病。月影议会既是白冠之乱的重要知情者，也是盟约最不愿公开得罪的证言来源。

这些关系都不是正式同盟。外部机构可以提供制衡，也可能借“监督”夺取禁术与星塔情报。玩家推动公开化时，必须同时决定谁能查阅、谁能否决，以及泄密造成的伤亡由谁负责。

## 8. 玩家声望与任务

盟约不使用公开声望条。系统记录：

- **可信度**：玩家能否在知道危险信息后遵守必要边界；
- **异议记录**：玩家是否要求证据、拒绝不可逆命令；
- **暴露度**：外界对玩家与盟约关系的察觉。

关键任务：

1. **〈没有目标的处决令〉**：命令要求抹除一间空屋，现场却只有被删除的居民生活痕迹。
2. **〈沉默也会传染〉**：一项异常只能通过公开描述被削弱，迫使盟约违背最少知情原则。
3. **〈第一个见证人〉**：玩家必须决定由时钟塔、教廷、公会或受害者联盟中的谁担任外部监督，每个选择都有泄密与权力代价。
