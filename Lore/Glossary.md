# 世界专名与术语表

本表用于统一剧情、UI、代码注释与本地化。正文首次出现已有词条时仍应链接到独立文档；术语表只负责短定义与禁用歧义。

## 1. 世界与历史

| 推荐写法 | 定义 | 避免混用 |
| --- | --- | --- |
| 厄达斯大陆 | 游戏主要大陆 | 不用来指全部多层现实 |
| 厄达斯界 | 包含大陆、星穹层与可能层的完整本地世界 | 玩家日常台词通常简称“这个世界” |
| 星塔历 | 世界熔炉稳定后的通用纪年 | “神历”带有教廷立场，不作中立纪年 |
| 星律民 | 被厄达斯称作神族的界外高位文明 | “神族”可作民间称呼，不等于真正神明 |
| 神代战争 | 星律民内战波及厄达斯的一系列战争 | 不是单场人魔决战 |
| 大背叛 | 战后政治叙事中的称呼 | 使用时注明说话者立场 |
| 蚀理 | 让单一解释逐渐排除所有矛盾的界外侵蚀 | 不写成能免除个人责任的普通洗脑 |

## 2. 世界设施与异常

| 推荐写法 | 定义 | 制作提示 |
| --- | --- | --- |
| 遥空庭院 | 瑟怜居所、观测站与召唤装置所在地 | 不是自由移动的普通天空城 |
| 世界熔炉 | 消耗可能性修补现世的核心设施 | 不具备无代价许愿功能 |
| 星塔网 | 测量、校准与分担熔炉负荷的设施网络 | 传送只是衍生功能 |
| 破碎空间 | 被世界熔炉切离现世的可能性 | 不自动等同真实过去或预言 |
| 地下城 | 拥有稳定入口与锚核的破碎空间俗称 | 可以位于地上、海上或天空 |
| 锚核 | 维持地下城内部逻辑的核心矛盾 | 不一定是 Boss 生物 |
| 定相 | 让可能层事物获得现世连续性的过程 | 用于解释战利品、结局与容量 |
| 余忆症 | 同时保留互相排斥记忆的状态 | 教廷与学界可有不同称呼 |

## 3. 魔法

| 推荐写法 | 定义 | 避免混用 |
| --- | --- | --- |
| 魔力 | 生灵与环境中可参与术式共鸣的能量和信息载体 | 英文 UI 可用 Mana；正文不写“星能”代替 |
| 魔导媒介 | 引导、放大或稳定术式的器具 | 媒介不是力量源 |
| 魔导体 | 能保存和传导魔力波形的材料 | 可天然形成或人工制造 |
| 六元素 | 火、冰、雷、水、风、土 | 灵魂、治愈等不属于自然六元素 |
| 高阶学科 | 灵魂、治愈、光、暗、奥秘、星界 | “高阶”表示学习条件，不保证伤害更高 |
| 学派 | 十二系的正式称呼，用于书面与译名 | 世界内台词可说“元素、术式、圣迹、咒法”；不写成“法系” |
| 零律 | 暂时切断目标与现行术式规则的高危干涉 | 不是第十三元素 |
| 星界能量 | 生灵的施术余裕，被时钟塔量化为可读的读数 | 不与“魔力”互换：魔力是世界内的能量载体，星界能量是可被测量的余裕。英文用 Astral Energy，不写 MP |
| 一式 | 一个完整的、可被传授的法术 | 不写成“技能点”；法术没有等级，只有说清楚与没说清楚 |
| 术式 | 写在书卷页边的改写与排布：调整一式，并决定几式如何同时或先后发声 | 不是新法术。主导永远是书卷所授的那一式 |
| 编织 | 在书卷页边完成上述改写的手艺 | 不吞掉书卷；编进去的都能拆回来 |
| 书卷 | 承载一式与其页边的载体，分启明、秘传、冠冕三级 | 与一次性“卷轴”不是同一物 |
| 作者档位 | 最初写下这一式的人认为它应该是什么样子 | 调离它在时钟塔叫“与作者商榷”，不叫“强化” |
| 串联 | 异形态的几式先后发声 | 与融合不可互换 |
| 融合 | 同形态的两式共用一次展开、轮流发声 | 不是“同时放两个法术” |
| 和鸣 | 全部法术同属一个学派时的省力现象 | 学院与教廷称“纯声”；不写成加成百分比 |
| 反应 | 前一式留下的元素印记与后一式的学派互相咬合 | 教廷曾称“借冲突取巧”；写作时注明说话者立场 |
| 负荷 | 一次呼吸要求现世重写多少东西 | 不是体力也不是魔力余量。超额时术式被**拒绝**，不是失败 |
| 阶位 | 一句话移动了多少世界，每两阶翻倍 | 不是强度排名，也不是等级 |
| 亲和 | 一个人能让某学派听懂他到什么程度 | 导师能测出，很难替人提高 |
| 铭刻 | 在绑定台把一式连同页边写进载体，书卷一次性花掉 | 解除铭刻不还回书卷 |
| 封式 | 页边封着、不可商榷的四式（探知、分身、传送门、世界传送门） | 封式由世界定，禁术由人定，两者不混用 |
| 页边手 | 市集上替人调整书卷的手艺人 | 他们不施法，只调档位 |
| 永恒系列 | 十二道永恒引导光束与翠星永辉；名字出自星律语，从未被翻译 | 时钟塔认为是转录而非发明，不写成“人类研发的终极魔法” |
| 主属性 | 体质、力量、灵巧、技力、感知、智力、决心七项身心底子 | 不写成“资质”：资质在游戏内指武器天赋 |
| 天赋 | 一个人与某种武器或某个学派的契合度 | 武器那一侧称资质，法术那一侧称学派亲和 |
| 命运轮环 | 时钟塔与冒险者公会共用的成长诊断术，也是它画出的星图的名字 | 不写成“星盘”，也不写成预言；旧提案的六路线星盘已废止 |
| 星轨 | 轮环上的七条路线：守御、战印、疾风、月刃、先见、星术、圣域 | 各对应一项主属性；用星轨名介绍一个人是学界习惯 |
| 命谱 | 出身时即成形的一组命途，分恩赐与负契 | 与命运轮环不混用：命谱是带来的，轮环是练出来的 |
| 命运天平 | 读命谱时衡量恩赐与负契的那套算法 | 旧稿的“命运调律”已废止 |
| 恩赐 / 负契 | 命谱上的两面：你带来的与你欠下的 | 绝大多数命途改变的是生活，不是战斗 |

## 4. 族群与组织

| 推荐写法 | 说明 |
| --- | --- |
| 魔族 | 外部历史形成的总称；内部按城邦、血缘与职业自称 |
| 鱼人族 | 水生族群的统一称呼，与游戏内显示名一致；“海裔”为已废止的旧提案用语 |
| 机械种 | 拥有人格与连续记忆的人工生命；“遗迹兵器”只指仍未觉醒者 |
| 冒险者公会 | 跨国职业与风险管理组织，不是单一国家军队 |
| 黯渊王庭 | 拉瓦妮尔领导的魔族城邦联盟 |
| 献炉 | 以未定型的幼年龙裔心核稳定黯渊旧星塔的族内说法。王庭公开场合仍用褒义语气，拉瓦妮尔本人拒绝使用这个词 |
| 重核症 | 献炉造成的进行性损伤：心核与破损重力锚永久融合，大规模重力术会扩大裂纹 |
| 月影议会 | 精灵之森的统治与记忆保管机构 |
| 寂无盟约 | 处理失控术式与法则异常的秘密组织 |
