# 货币、工价与生计

## 1. 词条摘要

> 「金币？我这辈子见过四枚，三枚是替别人数的。」
> ——澄晶前哨镇，临时劳工

厄达斯的钱不是国王规定的，而是**冒险者公会、商路银行与几个大国在长年结算里磨出来的重量标准**。地方硬币仍然各有名字、图案和成色；旅行者手里的币值之所以到处通用，靠的是公会账房愿意替它折算。

这份词条回答的是一个具体问题：**在厄达斯，一个普通人怎么活下去，而一个冒险者的生活和他们差在哪里。** 写聚落、写委托、写角色出身时，这是最常被用到的一层。

## 2. 三级币制与它的社会含义

跨国结算采用三级百进位：**铜币**、**银币**、**金币**。铜币是日常，银币是一周的分量，金币是一个决定。

| 单位 | 它在生活里的位置 |
| --- | --- |
| 铜币 | 一顿饭、一段车程、一把钉子。穷街区的小额交易几乎全在铜币里完成 |
| 银币 | 一夜旅店、一瓶药、一天的工钱、一件普通装备。普通人的储蓄以银币计 |
| 金币 | 高阶装备、房产、组织之间的交易。多数居民一生握在手里的金币数得清 |

大额交易走**公会汇票**或封印账户，角色不会扛着成箱金币上路——这既是治安常识，也是叙事方便。各国硬币成色不同，公会兑换所按重量与魔导印记折算，中间抽一道手续费；这道手续费是公会在边境城镇最稳定的收入之一。

**魔石不是法定货币。** 公会给出的稳定收购价让它看起来像硬通货，但价格会随纯度、区域需求与定相状态浮动。在星塔停运的那几周，矿工手里的魔石比金币更难出手——这件事发生过，边境的人都记得。

## 3. 普通人的工价与生活成本

这一组数字是全套经济的地基，其余价格都由它们推导。写任何「这个人怎么活下去」的段落时，先回到这里。

| 项目 | 大陆基准 | 说明 |
| --- | ---: | --- |
| 临时劳工日收入 | 55—80 C | 不含食宿，无技能门槛 |
| 学徒或店员日收入 | 70 C—1 S 20 C | 城市略高，同时要承担房租 |
| 熟练工匠日收入 | 1 S 20 C—2 S 50 C | 稀缺专业可更高 |
| 边境守备日收入 | 2—4 S | 含危险津贴，装备多为公发 |
| 一块黑面包 | 8 C | 最低热量来源 |
| 一碗今日炖菜 | 30 C | 热餐，冒险者的日常 |
| 一杯啤酒 | 12 C | 最常见的社交消费 |
| 旅店标准间 | 80 C / 夜 | 完整休息的基准 |
| 马厩大通铺 | 15 C / 夜 | 睡得着，但睡不好 |
| 公共浴室 | 12 C | 城镇卫生与社交的入口 |

**普通人不按旅客价格生活。** 他们靠家庭共住、长期租约、自产食物和雇主补贴把成本压下去；旅行者消费的是「随时可得、不需要关系」的零售价，因此明显更贵。一个本地人听到有人为一夜床铺付 80 C 时的反应，是真实的，也是好写的。

一个有用的换算：**一个临时劳工要不吃不喝干两百天，才能攒出一枚金币。** 任何以金币计价的东西——一栈房产、一把高阶武器、一次定相鉴定——在普通人眼里都属于另一个世界的物价。这条落差是厄达斯阶级感的来源，比任何「贫民区很破败」的描写都更有效。

## 4. 价格为什么会变

物价不是商店倍率，而是能被居民说清楚的因果。写聚落的货架与公告时，优先给原因，而不是给数字。

| 条件 | 居民感受到的变化 | 可见原因 |
| --- | --- | --- |
| 边境常态 | 进口品略贵 | 护卫工钱与道路损耗 |
| 魔物潮警戒 | 药品、箭矢明显上涨 | 公共征购叠加恐慌囤积 |
| 星塔停运 | 魔导器服务大幅上涨 | 必须改用人工校准，工时翻倍 |
| 丰收节 | 基础食物便宜，酒反而难买 | 季节供给与集体消费 |
| 外来者大量倾销同类货 | 收购价逐批走低 | 本地商人消化不掉库存 |
| 本地工坊得到投资 | 对应制作与修理变便宜 | 本地能力真实提升 |

**NPC 必须能解释显著变化。** 一个街角商人说「上游征购把药全收走了，你去问问诊所肯不肯分你半瓶」，比任何界面提示都更能让玩家理解这个世界在运转。

## 5. 冒险者公会与悬赏经济

委托人先交担保金，公会抽一成，用于登记、调查、救援储备与事后追责。这一成是公会能够存在的全部理由：**它不是任务板，而是一家替高风险劳动做结算与兜底的机构。**

评级衡量的是**最坏后果**，不是目标怪物有多强。一头可能冲进村子的野猪，评级可以高于一头躲在深林里的亚龙。

| 评级 | 典型委托 | 收入量级 | 它在生活里意味着什么 |
| --- | --- | --- | --- |
| F | 送件、寻物、清理害兽 | 铜币 | 今晚有床、明天有饭 |
| E | 哥布林小队、短途护送 | 几枚银币 | 攒第一件真装备 |
| D | 废矿调查、夜路巡逻 | 十几枚银币 | 开始买得起选择：地图、许可、备用药 |
| C | 首领讨伐、稳定裂口 | 几十枚银币 | 稳定职业收入，可以养家 |
| B | 城镇级灾害、长程护卫 | 接近金币 | 从个人生计进入地区政治 |
| A | 亚龙、腐化源、战略救援 | 数枚金币 | 高风险专业阶层，名字开始被记住 |
| S | 城市存亡、上古锚核、界外事件 | 十余枚金币以上 | 钱已经不是重点，后果才是 |

**失败不自动等于零收入。** 已完成的护送路段、带回的调查证据、依法产生的救援费用都能结算；真正触发罚金与降级的是欺诈、擅自扩大损失和隐瞒队员死亡。这条规则是公会「像一家职业机构」的最直接证据，也是最适合写冲突的地方——因为判定由人做出，而人会偏心。

**怪物不会凭空掉落钱币。** 钱来自人形敌人的携带物、委托结算与合法战利品拍卖；魔物提供的是能被现实经济消化的素材。一个把魔石背回镇上却卖不出去的新手，是厄达斯最常见的场面之一。

## 6. 住房、工坊与定居

住房是厄达斯最硬的阶级指标。边境一层小屋是多数冒险者的第一个现实目标，需要居住权或地区声望；城市联排住宅的价格由地段、税与维护差异拉开；工坊与商铺住宅还要附带经营许可和设备。庄园与战略地块属于后期建设，价格由政治权利而非建材决定。

**「普通民宅值几百金币」是错误的印象**，那个价位只适用于庄园、核心商铺或带政治权利的土地。普通居民通过长期租约、家族共有与雇主提供的住处解决居住，买房对他们不是储蓄目标，而是跨代事件。

住宅税与维护费真实存在，但它们的作用是让定居有重量，不是惩罚离开。长期拖欠会暂停经营与增益，不会抹掉一个人的家。

## 7. 谁被挤压

- **有媒介、有教育、有合法施术证的人**更容易进入城市中层；天赋普通的人靠预编魔导器工作，却要向专利持有者或行会付费。
- **魔导灯需要定期更换低纯晶砂**，所以贫困街区总是更早熄灯。这不是隐喻，是账本。
- **边境居民承担运输加价**，却最需要药品与箭矢。公会用统一采购压低新手刚需的价格，差额由高阶委托的手续费与镇防预算承担——这是一项真实的补贴，也是一项可以被削减的预算。
- **行会认证的技艺是没有战斗力的人立足的方式。** 铁匠、厨师与炼金术士各自掌握一套别人做不好的工序，这也是厄达斯的城镇不是只有冒险者的原因。

## 8. 故事落点

- **一枚金币等于两百天劳作。** 让角色第一次收到金币报酬时表现出不适，比任何贫富描写都有效。
- **担保金是道德难题的入口。** 委托人交不出担保金时，公会分部肯不肯私下受理，取决于柜台后面是谁。
- **汇票比金币更危险。** 一张公会汇票被挂失、被伪造或被持票人拒付，足以撑起一条城市调查线。
- **星塔停运期的物价是现成的灾难刻度。** 不需要描写恐慌，只要让药价说话。
- **「卖不出去的魔石」是新手的必经之路。** 它教会玩家这个世界有真实的供需，而不只有商店。
- **技艺行会的许可是一道看不见的门。** 一个手艺很好但没有认证的人，在城里做什么都合法，就是赚不到钱。
