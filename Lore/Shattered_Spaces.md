# 破碎空间与地下城

## 1. 词条摘要

破碎空间是世界熔炉修补现世时被切离的可能性。它们可能保存“如果那座城没有陷落”的过去，也可能展示“若某项选择继续下去”的未来。空间中的人、建筑与伤害在其内部都是真实的，但它们不自动等同于现世历史。

冒险者把规模较大、拥有稳定入口和内部锚点的破碎空间统称为地下城。地下城可以位于塔顶、海面或一扇普通房门后，“地下”只是沿用最早探索记录的习惯。

## 2. 形成与生命周期

破碎空间通常经历四个阶段：

1. **渗影**：现世出现重复脚步、错误倒影、同一物品的两个版本。
2. **开门**：空间裂口稳定到可以进入，附近魔物与天气受其内容影响。
3. **定相**：探索者的行为使其中一组因果逐渐固定，战利品开始能够带出现世。
4. **闭合或锚定**：核心矛盾解决后空间消散；若被星塔、公会或强大个体固定，则成为长期地下城。

不处理的空间不会永远静止。它可能扩大并覆盖现实，也可能因缺乏魔力自行崩解，把内部生物和物质随机抛入现世。

## 3. 地下城核心与“迷宫之主”

每个稳定地下城都有一个维持内部逻辑的**锚核**。它可以是怪物、物品、誓言、未完成的仪式，甚至一条必须反复发生的事件。冒险者习惯把锚核人格化为“迷宫之主”，但击杀最强生物不一定能通关。

真正的完成条件是解决锚核坚持的矛盾。例如：

- 一座永远守城的要塞，锚核可能是“援军必定到来”的军令；烧掉军令、等到援军或让守军接受撤退都会形成不同结局。
- 一片重复丰收日的农田，锚核可能是村民不愿承认旱灾已发生；掠夺粮仓只会让循环重置。
- 展示未来黯渊城的裂域，最强敌人可能是保护幼童的拉瓦妮尔幻影，真正锚核却是供水系统的最后阀门。

这种设计让地下城机制实现世界主题，而不是给普通洞穴换一层背景。

## 4. 定相、战利品与经济

空间内的物品只有在定相后才能长期存在于现世。未定相物品离开入口会变成无害灰砂或恢复成原本的可能状态。公会鉴定台通过稳定印记判断战利品能否交易。

一个地下城可带出的稳定质量有限，这解释了为什么冒险者无法无限复制金银、粮食或神器。锚核越强，定相额度越高；但过度抽取会让空间提前坍塌，困住仍在内部的队伍。

常见收益包括：

- 保留异常波形的魔石与魔导体；
- 现世已经失传、但材料仍兼容的工艺品；
- 只能作为证据、不能直接当作史实的记录；
- 被未来环境改变的生物素材；
- 与探索者选择绑定、无法转售的“因果遗物”。

经济数值见[经济与货币系统](../Systems/Economy_System.md)。所有高价值掉落都应说明定相条件、合法买家与为何尚未被公会垄断。

## 5. 探索制度与普通人的生活

冒险者公会对稳定入口实行登记、风险评级与回归点计时。进入者要留下血样或魔力签名，便于辨认“回来的人是否仍是同一个版本”。这项流程让新手不安，却来自真实事故。

破碎空间也改变了非冒险者：

- 边境农户会为“昨天还不存在的道路”设置红绳，不让孩子靠近；
- 旅店按预计闭合时间保留房间，逾期七日才清理失踪者物品；
- 商人雇用定相鉴定师，避免整车货物在关税站变成灰砂；
- 教廷为保留冲突记忆的人提供安定仪式，时钟塔则称其为余忆症治疗；
- 有些家庭拒绝认领从未来裂域回来的“成年孩子”，形成长期社会问题。

## 6. 玩法规则

| 机制 | 玩家体验 | 设计边界 |
| --- | --- | --- |
| 定相度 | 完成探索、理解矛盾或作出选择后提升 | 不等同清怪率，避免只靠战斗填满 |
| 余忆 | 带出额外情报或能力，也增加错误提示 | 必须可在 UI 辨识，不能无提示篡改玩家选择 |
| 回归点 | 队伍撤退、补给与存档锚点 | 深层区域不能随意快速传送 |
| 锚核分歧 | 允许击破、说服、替代或带走 | 不保证所有地下城都有和平解 |
| 定相额度 | 限制稳定战利品总量 | 用清晰容量或选择提示，避免隐藏惩罚 |

同一地下城可随主线重新开放为不同分支，但复用地图时必须改变路径、NPC 行为与锚核逻辑，不能只提高敌人数值。

## 7. 内容模板

新地下城至少定义：

1. 它从哪项未实现的历史或未来分离；
2. 入口为何在此刻、此地出现；
3. 锚核坚持什么矛盾；
4. 玩家如何从环境而非说明文字理解规则；
5. 至少一种非击杀解决方式，或明确为何不存在；
6. 可带出什么、谁会争夺、谁会因此受害；
7. 闭合后现世发生什么可见变化。
