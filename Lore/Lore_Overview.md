# 世界知识总览

## 1. 阅读分层

世界知识分为玩家可在公开资料中理解的**常识层**、通过阵营与角色线逐步获得的**争议层**，以及仅供剧情制作使用的**核心剧透层**。独立词条会在进入剧透前明确标记，公开图鉴不得无条件引用。

## 3. 核心因果链

星律民内战把厄达斯现实撕裂 → 瑟怜降格并启动世界熔炉 → 熔炉用未实现的可能性修补现世 → 被舍弃分支形成破碎空间 → 星塔网长期把中心地区风险外推 → 当代地下城、世界树异变、黯渊旧锚和玩家召唤在星塔历 987 年同时收束。

新增 lore 必须能接入这条因果链，或明确属于不依赖主线的地方知识。禁止用“另一个更古老的封印 / 更高位的幕后黑手”不断覆盖既有核心。

## 4. 制作规则

- 历史争议区分民间共识、机构叙事、证据与隐藏真相。
- 破碎空间只能提供一种可能性证据，不能当作万能历史录像。
- 光与暗不是善恶元素，神族也不是真正全知神明。
- 当代制度问题由当代人负责；蚀理只放大与收束选择，不替任何人免罪。

## 5. 词条边界

世界知识词条写的是**世界内的现象、称呼、制度与后果**。以下内容不进入本目录，也不进入本仓库任何词条：

- 数值、倍率、公式与层级表；
- 资源键、注册 ID 与占位符；
- 技能树节点、法术清单与实装进度；
- 美术、音频与关卡制作指令；
- 尚未实际存在的任务流程与状态变化。

这些属于[游戏内文档](https://kentomahou.com/)。每份词条以「权威边界」一节结束，指明对应的游戏内页面；两边冲突时以游戏内文档为正。详见[编写规范](../AUTHORING_GUIDE.md)第 2 节。
