# 系统待完成池

> **性质**：提案与待办，**不是设定** · **覆盖范围**：Systems 目录下的全部系统 · **状态词汇**：每条只有「完成」或「未完成」

## 1. 这份文档是什么

系统文档只记录**已经存在于游戏数据中的内容**。这份文档收纳它们的另一半：缺口、扩展提案，以及暂时不实装但不应该丢掉的设计思路。

三条规则：

1. **不写进度。** 每条只有「完成」或「未完成」两种状态。没有排期、没有百分比、没有阶段划分。优先级说明的是**先做哪个**，不是**什么时候做**。
2. **不写成设定。** 本文件 `status` 为 `draft`，不得被其他词条当作既成事实引用。一条实装之后，它的描述迁移到对应的系统文档，并从这里删除。
3. **每条都要说明它解决什么问题。** 只是“看起来很酷”不足以进入待办池。

## 2. 优先级

| 级别 | 含义 | 判断标准 |
| --- | --- | --- |
| **P0** | 矛盾、失效与可利用漏洞 | 文档与实装互相矛盾；玩家能拿到但不起作用；或存在可被利用的空档。放着不管会直接误导玩家或开发者 |
| **P1** | 骨架空缺 | 系统骨架已生效，但内容或防护成规模缺席，玩家能明显感到“这里应该有东西” |
| **P2** | 扩展 | 系统运作正常，这是让它更完整的提案 |
| **P3** | 设计储备 | 暂不实装，但不应丢失的设计思路 |

### 4.1 内容缺席

| 项目 | 现状 | 状态 |
| --- | --- | --- |
| 水系法术 | 有完整法强、有「潮湿」状态、有鱼人族联动，零个法术 | 未完成 |
| 光系法术 | 有完整法强、有「光耀」状态、有羽灵族联动，零个法术 | 未完成 |
| 兔人族能力 | 有头像、介绍与特征条目，无任何能力，未进入可选列表 | 未完成 |
| 机械种能力 | 同上 | 未完成 |
| 命运轮环中位被动 | 七条星轨各有一个已定义但未落位的招牌被动 | 未完成 |
| 命运轮环属性节点 | 盾势值回复速度、近战暴击伤害、隐蔽效能、魔法暴击伤害各有一对节点已定义但未落位 | 未完成 |

**水系与光系优先级最高。** 鱼人族「镜水结界」与羽灵族「神代余音」都建立在这两系的法强之上，玩家却拿不到任何对应法术，只能靠装备被动堆法强。这是唯一一处种族设计已完成、法系内容却完全缺席的组合。

**中位被动的缺席**是命运轮环最具体的体验问题：从第一层到 90 级冠位之间没有任何里程碑。补完不需要新设计，只需要落位。

**兔人族与机械种的设计方向。** 两者的现有介绍已经给出锚点，且都能填补当前没有种族占据的生态位：

- **兔人族**——极佳的跳跃与灵巧、上古月光加护。对应到已有属性，应当围绕「闪避率」「闪避反击倍率」与移动建立循环，用月相或昼夜作为强度开关。当前没有任何种族把闪避当作资源。
- **机械种**——遗迹守卫兵种、无机体。应当围绕「已探知」状态、「隐蔽效能」的对抗面与一条自伤式过载资源建立循环，并以“不吃常规食物、依赖修理”作为生活层的代价。当前没有任何种族占据信息位。

两者都必须满足第 8 节的种族设计约束。

| 命运轮环洗点 | — | 重置代价、等级限制与据点限制均未定义 | 未完成 |

成长路径是**投入产出比最高的一项**：整条管线已经跑通，缺的是内容——边、解锁条件与星图排版。

设计时必须先接受一条已实装的性质：**这套系统天然可逆。** 首次跨越一条边要付条件与消耗，但两端都解锁之后，玩家可以自由往返且不再付出任何代价。因此每一条边都要按“玩家会反复横跳”来设计，不能把它当成一次性的单向门；如果某条路径确实需要不可逆，那要么另加机制，要么重新考虑它是否该做成边。

三层的补完顺序建议按确定性排：职业与技艺的晋升路径目标明确（见第 5.1、5.2 节的扩展池），种族进化则需要先回答“上位种族到底提供什么”——在此之前不应铺开更多上位节点。

## 5. P2 · 扩展

### 5.1 职业扩展池

七个已实装职业遵循一条规律：**每个职业持有一到两种适性。** 适性矩阵恰好留下两个空位，而这两个空位正对应两个已在剧情中出现、系统里还不存在的职业。

| 适性组合 | 已实装 | 空位 |
| --- | --- | --- |
| 近战 | 战士、重战士 | — |
| 远程 | 射手、猎人 | — |
| 魔法 | 魔法师、神官 | — |
| 近战 + 魔法 | 牧师 | 尚有一格 |
| 远程 + 魔法 | — | **空** |
| 近战 + 远程 | — | **空** |

**魔弓手**（远程 + 魔法，基础职业射手）。它把星界能量投射到远处，而不是把箭射得更远。与同系职业的区别写在资源上而非数值上：射手靠距离换伤害，猎人靠标记与收割时机，魔弓手靠元素状态与星界能量循环。它是唯一能同时受益于「元素力」阶梯与「远程暴击」属性的职业，这个交叉点本身就是它的身份。精灵族「精灵之谐」已经实现了“射击附加最高元素属性伤害”的原型，魔弓手应当把这个思路做成职业级机制，而不是复制它。

**斥候**（近战 + 远程）。唯一不涉及魔法的双适性组合。身份建立在已有的「隐蔽效能」属性与「遁影」状态之上：隐蔽效能目前只有猫人族与先见冠位提供，没有职业围绕它构筑；「已探知」目前只有猎人在利用，斥候可以从对抗面切入。风险是与猫人族生态位重叠——若实装，两者的资源必须不同，猫人族用翻滚触发「影刃」，斥候不应再用翻滚。

**魔剑士**（近战 + 魔法的第二格）。牧师已占据这一组合的一格，定位是战场救援（近战命中治疗友军）；魔剑士占据另一格，定位是把法系伤害灌进近战（力量 + 智力，近战命中转化为元素伤害与状态）。「近战物理法强」与「魔剑感知」两项属性已注册但未接入机制，**看起来正是为这个职业预留的**，确认这一点是实装魔剑士的第一步。附魔切换应当消耗星界能量而不是冷却，让它与魔法师的资源竞争关系成立。

**叙事依赖。** [艾瑟琳德・凡・厄里丹](../Characters/Aethelind_Vane_Eridan.md)的固有职业登记为魔弓手，[拉瓦妮尔・阿斯莫德斯](../Characters/Rhavaniel_Asmodeus.md)登记为重力魔剑士。在职业实装前，这两处描述属于叙事设定而非系统事实。

### 5.2 技艺扩展

判断标准是“已有工作站或生产系统，但没有对应技艺”。当前符合条件的候选：

| 候选 | 已有系统 | 技艺可以改变什么 |
| --- | --- | --- |
| 宝石匠 | 宝石镶嵌系统（嵌石小刀、巧匠透镜、虚空蚀凿、金缮凝脂等） | 镶嵌成功率、词条品质、拆卸损耗 |
| 制图师 | 蓝图系统 | 蓝图产出率、抄录效率、稀有蓝图解析 |

两者都未定案。**不为了凑数增加技艺**——一个技艺如果不能明确说出“没有它会慢多少、差多少”，就不应该存在。

## 6. P3 · 设计储备

以下设计来自早期技能设计稿。它们描述的内容与当前实装不符，因此不作为设定；但其中的**规则思路**仍然成立，值得在对应内容实装时采用。

| 保留项 | 解决的问题 | 与当前系统的关系 |
| --- | --- | --- |
| **命运透支**：所有免死、致命承担与余烬类效果共享一个标签，同一场战斗只能成功触发一次 | 免死叠加 | 直接对应 P0 的免死漏洞。这是储备中价值最高的一条 |
| **首领控制转化**：对首领的硬控统一转为盾势伤害、减速或可读短硬直，而不是免疫 | 控制在高难度内容中失去价值 | 「最大盾势值」与「破盾效能」已实装，转化的接收端已经存在 |
| **状态联动可读性**：元素联动必须以可见状态为前提，禁止隐藏乘区 | 玩家无法理解伤害来源 | 「潮湿」「霜结」「通电」等状态已实装，规则可直接套用 |
| **探索术必须有替代路径**：任何用于通行的法术都必须存在道具、NPC、地形或更高成本的替代方案 | 法术成为关卡的唯一钥匙 | 「探知魔法」「传送门」已实装，规则应在关卡设计时生效 |
| **地面危险的统一轮廓语言**：友方细边、敌方实边、中立双边，不只依赖红绿区分 | 色觉可达性 | 尚无对应实装，属于 UI 规范储备 |
| **技能详情固定字段**：类型、资源、触发条件、持续、冷却、反制、标签 | 描述格式不一致 | 技能类型提示已实装前三项标签，其余字段待补 |
| **绝对表述限制**：“必定、完全免疫、无视一切”只用于剧情级效果或明确有限的窗口 | 绝对值难以平衡 | 与 P2 的绝对表述处理直接相关 |

**不进入储备的早期设计**，理由一并记录以避免反复提出：

- **六职业体系（战士／射手／魔法师／斥候／魔剑士／魔弓手）**：已被七职业体系取代。其中三个职业名进入第 5.1 节，体系本身不保留。
- **十二系各 11 项、共 132 项法术的清单**：与实装的 24 个法术相差一个数量级，作为清单没有参考价值。单个法术构想可在补完水系与光系时挑选，但不整体保留。
- **六路线星盘与 99 点成长**：已被命运轮环取代。
- **十六项通用技能**：其功能已分散进种族能力、职业被动与技能树节点，不需要独立的第三套技能。

| 法系密度是否拉平 | **拉平**，目标为每系 6 项核心法术、合计 72 项；角色变体与跨系法术不占配额 | 未完成 · 按水、光、暗、土、风的顺序补完 |
| 经济价格表的地位 | **设计目标**，IsekaiExpansion 的商人报价向它对齐 | 未完成 · 文档已重新推导，需回灌 `trade_overrides` |

## 8. 提案准入约束

新内容必须同时满足以下约束。它们来自已实装内容的实测量级，不是主观偏好。

### 8.1 种族

- 复杂度上限参考狐妖族：至多四项能力，其中至多两项主动，围绕**一种**自有资源建立循环；
- 每个种族必须有一条明确的代价，而不只是条件；
- 属性转化一律单向（如技力 → 近战暴击伤害），不构成循环；
- 新增绝对免疫需要在 P0 或 P2 登记并说明为何无法用高抗性替代。

### 8.2 职业

新增职业必须提供完整的五件套（`_levelup`、`_classbonus`、适性许可、招牌被动、`_starterkit`），并遵守：

- 初始资质加值总量 30 点，只改变分布；
- 招牌被动量级落在 +12% 至 +18% 区间，或等价的条件收益；
- 双适性职业不得在任一方向超过对应专精职业；
- 不新增第四种适性类别。

### 8.3 技艺

- 技艺**不提供任何战斗数值**，这条不容妥协；
- 技艺不改变配方能否做出，只改变做得多快、多好、多稳；
- 没有对应技艺的角色仍可使用全部工作站，只是拿不到品质与效率上限。

### 8.4 命运轮环

- 不新增星轨，七条星轨与七项资质一一对应，这个关系是闭合的；
- 单条星轨全通花费不得超过可花费点数上限，否则“专精到底”将不可达成；
- 普通节点量级维持在 +1 资质、+1%—+3% 属性，强化节点约为三倍；
- 冠位是唯一的强力节点，且必须保持同星轨二选一。

### 8.5 法术

- 新增法术必须同批登记星界能量消耗，否则该法术不消耗资源；
- 法系归属必须与效果一致；
- 描述先写结果，再写条件与代价。
