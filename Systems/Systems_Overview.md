# 游戏系统总览

## 1. 系统目标

系统必须让世界设定进入玩家决策：魔法通过状态和环境互动，经济通过食宿、任务与建设，职业通过身体起源和训练差异，星盘通过个人成长路线。系统文档同时服务玩法、程序、UI 与本地化，不把未实测数值写成永不更改的世界真理。

## 3. 跨系统规则

- 货币内部以铜币整数存储；显示自动换算 G / S / C。
- 光系不对所有魔族自动克制，种族不承担历史偏见形成的底层数值惩罚。
- 所有免死共享“命运透支”，冷却重置不作用于免死与终极。
- 地下城战利品受定相额度限制，商店价格必须有地区状态解释。
- 探索能力提供低成本路径，但关键内容始终存在道具、NPC 或高成本替代。

## 4. 尚待原型验证

基础 HP / MP、攻击与防御公式、控制积累、冷却缩减上限、等级上限和完整技能栏数量仍需战斗原型决定。验证结果应进入独立数值表，避免在多个叙述词条中重复修改。
