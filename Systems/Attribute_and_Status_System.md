# 属性、天赋与状态系统

> **实装状态**：已实装 · **核对**：与 IsekaiExpansion 游戏数据逐项核对 · **主要缺口**：「天咒亲和力」与「魔剑感知」已注册但未接入机制 · 全部待办见[待完成池](Pending_Pool.md)

## 1. 玩家承诺与范围

这是全作的数值骨架：**角色由哪些数字定义、一次攻击按什么顺序结算、战场上的状态各自代表什么。**

骨架的四个部分都已完整实装：

- **七项资质**是角色底层素质，由职业、等级、命运轮环与命运调律共同决定；
- **战斗属性**是资质与装备汇总后的实际表现，每一项在战斗公式里都有明确位置与上限；
- **天赋**记录角色对某类武器或某个法系的适性等阶，直接改变对应伤害；
- **状态效果**是战场上可读的短期变量，也是各系统之间互相咬合的接口。

本文件只记录已经生效的规则。法系的内容层（有哪些法术、覆盖到哪一步）见[魔法与法术系统](Magic_and_Spell_System.md)。

## 2. 世界内解释

“资质”与“天赋”在世界内是两件不同的事。资质是身体与心性的底子，可以靠训练缓慢改变；天赋是一个人与某种武器或某个法系之间的契合度，导师能测出来，却很难替你提高。冒险者公会的身份凭证上同时印着两者，因为委托评级要看的是“你能扛多久”，而不只是“你会什么”。

星界能量则是被时钟塔量化过的施术余裕。它见底时人不会立刻倒下，但接下来的每一个术式都会开始伤害自己——这也是公会把能量读数写进出勤记录的原因。

## 3. 七项资质

| 资质 | 内部键 | 含义 |
| --- | --- | --- |
| 体质 | `constitution` | 承受苦战的根本资质 |
| 力量 | `strength` | 驾驭肉体力量的资质 |
| 灵巧 | `dexterity` | 操控身法与投射武器的资质 |
| 智力 | `intelligence` | 理解奥术法则与原初系法术的资质 |
| 技力 | `technique` | 把握战机与招式精度的资质 |
| 感知 | `perception` | 洞察战场细微变化的资质 |
| 决心 | `belief` | 维系灵魂、信念与内在决心的资质 |

资质有四个来源：职业初始加值（每个职业合计 30 点）、职业每级成长（每级 1 点，方向由职业决定）、[命运轮环](Fate_Constellation_System.md)节点、种族被动（人族「冒险者之心」是唯一全面提升七项资质的能力）。

## 4. 战斗属性

### 4.1 资源

| 属性 | 键 | 作用 |
| --- | --- | --- |
| 最大星界能量 | `max_energy` | 施展主动技与法术可消耗的能量上限 |
| 星能回复速率 | `energy_regen_speed` | 每秒实际恢复的星界能量 |
| 星能汲取 | `energy_leech` | 普通攻击与法术命中后按最大星界能量比例回能，至少 1 点 |
| 最大盾势值 | `max_shield_gauge` | 装备盾牌在防御崩溃前可消耗的盾势资源 |
| 盾势值回复速率 | `shield_gauge_regen_speed` | 按盾牌单次恢复量与恢复间隔换算出的每秒盾势恢复 |

星界能量是全系统的第二资源条：法术消耗它，魔族用它抵伤，羽灵族在滞空时用它换法强，魔法师用它的剩余比例换伤害。

### 4.2 暴击

| 属性 | 键 | 说明 |
| --- | --- | --- |
| 近战／远程／魔法暴击率 | `melee_crit_chance`、`range_crit_chance`、`magic_crit_chance` | 对应类别攻击转化为暴击的概率 |
| 近战／远程／魔法暴击伤害 | `melee_crit_damage`、`range_crit_damage`、`magic_crit_damage` | 暴击最终伤害倍率，已包含普通一击的 100% |

近战暴击伤害的成长按所示增量的两倍结算，这是三类暴击中唯一的特例。

### 4.3 贯通与压制

| 属性 | 键 | 说明 |
| --- | --- | --- |
| 护甲贯通 | `armor_penetration` | 物理近战与远程无视对应比例护甲，最高 100% |
| 魔法贯通 | `magic_penetration` | 无视对应比例通用法术抗性，最高 100% |
| 破盾效能 | `shield_break` | 目标正以尚未破势的盾牌防御时追加伤害 |
| 异常命中率 | `debuff_accuracy` | 提高异常克服目标韧性的成功率，100% 时支持该机制的异常必定命中 |
| 伤害追加等级 | `bonus_damage_level` | 决定「伤害追击」追伤的等级 |
| 奥义伤害 | `burst_damage` | 仅对被判定为奥义爆发的攻击提供额外伤害 |

### 4.4 条件增伤

| 属性 | 键 | 说明 |
| --- | --- | --- |
| 浑身 | `stamina` | 按当前生命比例提高伤害，生命全满时获得完整增益 |
| 背水 | `enmity` | 按已损失生命比例提高伤害，濒死时获得完整增益 |

浑身与背水是一对镜像属性，让“稳住不掉血”与“压着血线打”成为两条互斥但等价的构筑方向。

### 4.5 生存与节奏

| 属性 | 键 | 说明 |
| --- | --- | --- |
| 韧性 | `tenacity` | 按比例缩短控制持续时间，最高 95%；同时抵抗敌方异常命中 |
| 闪避率 | `evasion` | 完全避开一次符合条件攻击的概率 |
| 闪避反击倍率 | `evasion_counter` | 成功闪避后对附近攻击者反击，按自身攻击伤害比例结算 |
| 根性触发率 | `guts_chance` | 遭受致命伤害时以 1 点生命存活的概率；虚空与疾病伤害绕过根性 |
| 环境抗性 | `environmental_resistance` | 减轻火焰、熔岩、冰冻、脱水、仙人掌与甜浆果丛等环境危害，受系统减伤上限约束 |
| 生命增幅 | `heal_amplification` | 受到支持该机制的治疗时的总增益 |
| 护盾强效 | `shield_power` | 按「1 + 增益」倍率放大盾势强度，以及其他受该属性影响的效果 |
| 全能吸血 | `omnivamp` | 按造成伤害比例恢复生命；同一刻命中的额外目标只提供正常恢复量的 22% |
| 技能急速 | `ability_haste` | 实际冷却 = 基础时间 × 100 ÷（100 + 技能急速） |
| 仇恨倍率 | `aggro_generation` | 敌对目标选择与攻击命中时采用的实际仇恨倍率 |
| 隐蔽效能 | `stealth_efficiency` | 缩短敌对生物侦测距离，100% 时常规被动侦测完全失效 |

技能急速采用倒数曲线而非线性减免，因此不存在“冷却归零”，只有收益递减。这是全系统的冷却上限保护，其他系统不需要再各自设上限。

### 4.6 社交与特殊

| 属性 | 键 | 说明 | 状态 |
| --- | --- | --- | --- |
| 口才 | `eloquence` | 满足对话、交涉与说服条件的言语资质 | 完成 |
| 魅力 | `charm` | 满足社交、影响与感召条件的人格魅力 | 完成 |
| 天咒亲和力 | `tenju_affinity` | 与「天咒」状态相关的适性 | 未完成 · 已注册，未接入机制 |
| 魔剑感知 | `magic_sword_sense` | 与魔剑机制相关的适性 | 未完成 · 已注册，未接入机制 |

口才与魅力是唯二不参与战斗公式的属性，它们服务于对话与声望检定。

## 5. 法强属性与三级阶梯

十四种法强已注册，其中十二种构成三级共鸣阶梯：上位属性同时抬升下位属性与自己直属的三个法系。

| 层级 | 汇总属性 | 直接强化 | 同时抬升 |
| --- | --- | --- | --- |
| 第一级 | 元素力 `elemental_power` | 火、水、冰、风、土、雷 | — |
| 第二级 | 浊以太 `dys_aether` | 奥秘、灵魂、暗 | 元素力 |
| 第三级 | 以太能量 `aether_power` | 治疗、光、星界 | 浊以太 |

| 法强 | 键 | 层级 |
| --- | --- | --- |
| 火 | `spell_power:fire` | 元素 |
| 冰 | `spell_power:frost` | 元素 |
| 雷 | `spell_power:lightning` | 元素 |
| 水 | `magic_water` | 元素 |
| 风 | `magic_wind` | 元素 |
| 土 | `magic_earth` | 元素 |
| 奥秘 | `spell_power:arcane` | 浊以太 |
| 灵魂 | `spell_power:soul` | 浊以太 |
| 暗 | `magic_dark` | 浊以太 |
| 治疗 | `spell_power:healing` | 以太 |
| 光 | `magic_light` | 以太 |
| 星界 | `magic_astral` | 以太 |
| 血 | `magic_blood` | 阶梯外 |
| 近战物理 | `magic_physical_melee` | 阶梯外 |

阶梯的设计后果是明确的：**投资高位属性比投资单一法系更划算，但代价是没有任何一系达到专精上限。** 血属性与近战物理法强不在阶梯内，只能通过专属来源提升——血属性目前由鬼族「修罗道」按损失生命比例提供，近战物理法强服务于武器侧的法术化伤害。

各法系在内容上分别负责什么，见[魔法与法术系统](Magic_and_Spell_System.md)。

## 6. 天赋

天赋是按等阶记录的适性，独立于资质与法强，直接改变对应伤害，也可以作为技能解锁条件（`需求天赋：<天赋> 高于等于等阶 <N>`）。

| 分组 | 数量 | 条目 |
| --- | ---: | --- |
| 元素适应性 | 6 | 火、冰、水、风、雷、土 |
| 高阶法系亲和 | 6 | 奥术本源、星辉共鸣、暗渊亲和、生命编织、圣穹恩典、御灵之术 |
| 星能资质 | 1 | 星能量（灵魂容器上限） |
| 近战武器资质 | 18 | 剑、刺剑、大剑、长柄刃、匕首、骑枪、镰刀、战斧、戟、长枪、钉头锤、战锤、魔杖、杖术、刀术、环刃、拳法、回旋镖 |
| 远程武器熟练度 | 4 | 弓术、弩术、火器、魔导枪 |

二十二项武器天赋与武器类型表一一对应，因此“换一把武器”在系统上等于“换一条成长曲线”，而不只是换外观。高阶法系亲和的六项与法强阶梯的第二、三级完全对齐。

## 7. 伤害管线

一次攻击按固定顺序结算，越靠前的层级量级越大，越靠后越细。

| 顺序 | 层级 | 量级 |
| ---: | --- | --- |
| 1 | 职业适性 | 近战／远程伤害减半；魔法直接禁止施放 |
| 2 | 天赋等阶 | 按适性等阶调整 |
| 3 | 资质与装备属性 | 基础伤害构成 |
| 4 | 元素克制 | 克制 ×1.25 起，被抗 ×0.75 起 |
| 5 | 暴击 | 按类别暴击率与暴击伤害 |
| 6 | 贯通 | 无视对应比例护甲或法抗 |

### 7.1 克制倍率

克制关系按目标类型判定，不是法系之间的固定相克表。

| 判定 | 倍率 |
| --- | --- |
| 克制 | ×1.25，每多一层克制再 +0.1 |
| 被抗 | ×0.75，每多一层抗性再 −0.1，最低不低于 0 |

单层克制的收益（+25%）刻意小于职业适性惩罚（−50%），因此**元素选择是优化，职业适性才是门槛**。职业适性的完整规则见[种族、职业与技艺](Origin_Class_Profession_System.md)。

## 9. 命运调律

命运调律是角色创建阶段的点数分配界面，是资质与装备之外的第三个属性来源。

**规则。** 恩赐消耗调律点数并强化角色，界面以青绿色符文与负数标记；负契返还点数并带来缺陷，以紫色符文与正数标记，且返还总量有上限。部分命途需要前置命途或与其他命途相斥，一份命谱可容纳的命途数量有上限，最终由服务器校验后「定律」。命途分为通用、体魄、奥术、心性、人际、生存、特殊七类。

| 恩赐 | 负契 | 影响 |
| --- | --- | --- |
| 铁根之躯 | 琉璃之躯 | 最大生命值 ±2 |
| 御风轻步 | 铅缚步履 | 移动速度 ±5% |
| 深邃星泉 | 残裂星脉 | 最大星界能量 ±6、能量恢复速度 ±0.05 |
| 学者灵光 | 思绪游离 | 冒险者等级经验获取 ±10% |
| 长路远望 | 囿于寸光 | 每日战斗与战利品经验上限 ±20% |
| 乐观性格 | 消极性格 | 舒适度恢复、损失与衰减速度 |
| 辞锋如银 | 拙于言辞 | 口才 ±8 |
| 魅力四射 | 寡淡无华 | 魅力 ±8 |
| 面相和善 | 面相狰狞 | 仅对通缉阵营的声望回升与损失 |
| 风霜识途 | 未历风霜 | 受到的环境伤害 ∓10%（不影响攻击与虚空伤害） |
| 大胃王 | 小鸟胃 | 最大饱食度 20 → 26 或 20 → 14 |

**预设：** 远行客、星界学士、百炼之身、险中求胜。

十一组命途中只有三组（生命、移速、星能）直接进入战斗公式，其余作用于经验、社交、声望、舒适度与饱食度。这条比例是刻意的：命运调律应当改变**你怎么过日子**，而不是替代职业与种族决定你怎么打架。

## 10. 平衡与滥用防护

- **所有百分比上限都写在属性描述里**：韧性 95%、贯通 100%、异常命中率 100%、隐蔽效能 100%。技能急速用倒数曲线取代硬上限。
- **全能吸血对额外目标只结算 22%**，防止范围攻击把吸血变成无限续航。
- **药水疲劳**限制生命与星能药水的循环使用频率，使资源管理保持有效。
- **克制倍率有下限保护**（不低于 0），不会出现负伤害。
- **管线顺序固定**，不存在隐藏乘区；玩家看到的每一层都能在角色状态界面里对上。

## 11. UI、程序与本地化

- 法强属性使用双命名空间：`attribute.isekaiexpansion.*` 与 `attribute.spell_power.*` 指向同一批显示名，两处必须同步修改。
- 属性描述统一先写结果、再写条件与例外，并给出可验证的上限（“最高 95%”“最高可贯通 100%”），不使用“毁灭性、绝对、无限”这类不含实现信息的形容。
- 「冒险者状态」界面按成长、固有能力、核心属性、每日额度、当前状态、战力、近战、远程、防御、抗性分节展示，节标题与本文件的分组保持一致。
- 状态图标需要显示来源、剩余时间、叠加层数与可净化性。
- 光系不对魔族自动克制；克制关系按目标类型判定，不把历史偏见写进底层数值。
