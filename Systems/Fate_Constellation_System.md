# 命运轮环技能树

> **实装状态**：建设中 · **核对**：与 IsekaiExpansion 游戏数据逐项核对 · **主要缺口**：七个主动技能不附带战斗效果；七条星轨各缺一个已定义但未落位的中位被动 · 全部待办见[待完成池](Pending_Pool.md)

## 1. 玩家承诺与范围

命运轮环是种族与职业之外的通用成长。它不提供第二套职业技能，而是把七项资质排成一个闭环，让玩家决定**把有限的点数投进哪一段圆环**。

三条数字定义了它的全部张力：

| 数字 | 值 | 后果 |
| --- | ---: | --- |
| 全树节点总数 | 379 | 树很大 |
| 全树总花费 | 764 点 | 全部点亮需要 764 点 |
| 可花费上限 | 100 点 | 你最多只能拿到其中约 13% |

玩家每提升一级角色等级获得 1 点，初始 1 点，技能树默认解锁。**一条完整星轨恰好需要 97 点**——刚好在上限之内，也刚好意味着“全通一条星轨”是一个真实但极端的选择，完成后只剩 3 点。

## 2. 世界内解释

命运轮环是时钟塔与冒险者公会共用的成长诊断术。导师把一个人的动作习惯、魔导体回路与压力反应投映成可阅读的星图，再用训练与媒介稳定其中一条连接。它不是命运书，也不会凭空把陌生技巧塞进脑中；点亮一个节点代表这个人完成了对应的训练，系统只是把训练结果画了出来。

七条星轨首尾相接，是因为时钟塔的观测认为七项资质本就互相牵引：练到极处的体质会回过头影响力量，而信念的尽头又通向体质。汇流节点画在两条星轨之间，代表的正是这些交界处的训练。

## 3. 结构

### 3.1 整体形状

```
                 鉴定（根节点）
                       │
       守御 ── 战印 ── 疾风 ── 月刃 ── 先见 ── 星术 ── 圣域
        └──────────────────（汇流环）──────────────────┘
```

- **根节点**：`鉴定`，花费 1 点，通过兼容的信息查看界面揭示准星所指目标的情报。它是进入全树的唯一入口。
- **七条星轨**：每条对应一项资质，各自 54 个节点。
- **汇流环**：相邻两条星轨之间有 6 个汇流节点，把七条星轨连成闭环。

### 3.2 单条星轨的内部结构

每条星轨由一个「之召」起始节点、五个层级、两个互斥冠位构成。

每一层包含九个节点：

| 位置 | 内容 | 花费 |
| --- | --- | ---: |
| 左路·入口 | 该星轨的左侧属性 | 1 |
| 左路·纵深 | 同属性强化版（第三至五层改为主动技能） | 2（主动为 0） |
| 中路·入口 | 该星轨的核心资质 +1 | 1 |
| 中路·纵深 | 核心资质 +3 | 2 |
| 右路·入口 | 该星轨的右侧属性 | 1 |
| 右路·纵深 | 同属性强化版 | 2 |
| 左织式 | 核心资质 +1 与左侧属性同时提升 | 3 |
| 右织式 | 核心资质 +1 与右侧属性同时提升 | 3 |
| 进阶门 | 核心资质 +3，需满足已花费点数与等级双重条件 | 2—3 |

**织式节点是星轨的经济核心。** 单点属性 1 点、强化属性 2 点，而织式用 3 点同时给出资质与属性——它比分别购买更贵，但更省节点位，是深入一条星轨时的正解。

### 3.3 单条星轨的花费

| 段落 | 花费 |
| --- | ---: |
| 之召 | 1 |
| 第一层 | 17 |
| 第二层 | 18 |
| 第三层 | 15 |
| 第四层 | 15 |
| 第五层 | 15 |
| 冠位（二选一，各 8） | 16 |
| **合计** | **97** |

第三至五层比前两层便宜 3 点，原因是这三层的左路纵深被替换成主动技能节点，而主动技能节点不消耗点数。

## 5. 解锁条件

节点同时受**已花费点数**与**角色等级**约束，两者都满足才能点亮。

| 位置 | 需已花费点数 | 需角色等级 |
| --- | ---: | ---: |
| 第一层进阶门 | 8 | 10 |
| 第二层进阶门 | 17 | 20 |
| 第三层进阶门 | 32 | 35 |
| 第四层进阶门 | 47 | 50 |
| 第五层进阶门 | 67 | 70 |
| 冠位 | — | 90 |
| 主动技能 1／2／3 级 | — | 30 ／ 50 ／ 70 |
| 汇流节点（第零至第五组） | — | 5 ／ 15 ／ 25 ／ 42 ／ 60 ／ 80 |

已花费点数是**全树累计**，不是本星轨累计。这意味着一个把点数摊在三条星轨上的玩家，同样能推开某条星轨的进阶门——广度构筑不会被门槛机制单独惩罚。

## 6. 汇流环

汇流节点连接相邻两条星轨，每个花费 2 点，同时提升两侧的核心资质各 1 点。

| 汇流 | 提升 |
| --- | --- |
| 体质·力量汇流 | 体质 +1，力量 +1 |
| 力量·灵巧汇流 | 力量 +1，灵巧 +1 |
| 灵巧·技力汇流 | 灵巧 +1，技力 +1 |
| 技力·感知汇流 | 技力 +1，感知 +1 |
| 感知·智力汇流 | 感知 +1，智力 +1 |
| 智力·决心汇流 | 智力 +1，决心 +1 |
| 决心·体质汇流 | 决心 +1，体质 +1 |

每对相邻星轨之间有 6 个汇流节点，分布在第零到第五层，全环共 42 个、合计 84 点。汇流是唯一的横向通路：不经过汇流就无法从一条星轨走到相邻星轨，这让“混合两条星轨”始终有一个可计算的入场费。

## 7. 主动技能原型

每条星轨在第三、四、五层的左路纵深各放置一个主动技能节点，对应同一个技能的 1—3 级。这些节点**不消耗点数**。

| 星轨 | 主动技能 | 设计意图 |
| --- | --- | --- |
| 守御 | 王域·不落神盾 | 展开随自身移动的守护领域，将承受的压力转化为盾势，终结时释放储存力量形成护卫脉冲 |
| 战印 | 勇者突袭 | 进入可控制方向的冲锋，斩击沿途敌人，并强化下一次全力近战攻击 |
| 疾风 | 坠星箭雨 | 指定弧形射击区域并降下箭雨；高等级收束散布范围，并奖励远距离站位 |
| 月刃 | 千重刃界 | 进入短暂技巧架势，连续施展自动修正目标的斩击，终结一击继承此前累积的精准度 |
| 先见 | 天启刻印 | 洞察目标的因果弱点并向队友揭示，将时机准确的攻击转化为逐步提高的异常命中能力 |
| 星术 | 星界新星 | 将元素力压缩为不稳定星核，自主选择释放位置，并引发随元素属性变化的后续冲击 |
| 圣域 | 圣域显现 | 圣化一片区域以稳定受伤的队友并强化其受到的护盾，最终释放延迟触发的奇迹脉冲 |

**状态：未完成。** 七个主动技能均已完成实现骨架，但在玩家动画与 Effekseer 特效完成前，执行逻辑被刻意留空，目前不附带任何战斗效果。技能树界面用金色六边形标记这些节点，分类描述中也明确写出了这一点，不对玩家隐瞒。

## 8. 已建档但未放置的节点

以下定义存在于技能树定义文件中，但没有出现在任何节点位置上。它们不是废弃内容，而是尚未落位的设计，状态为**未完成**。

### 8.1 七条星轨各缺一个中位招牌被动

| 星轨 | 未放置的被动 | 效果 | 花费 |
| --- | --- | --- | ---: |
| 守御 | 不坏之躯 | 体质 +4，韧性 +5% | 3 |
| 战印 | 斗争本能 | 力量 +4，护甲贯通 +3% | 3 |
| 疾风 | 弓手律动 | 灵巧 +4，远程暴击率 +3% | 3 |
| 月刃 | 无瑕架势 | 技力 +4，技能急速 +3 | 3 |
| 先见 | 第六感 | 感知 +4，闪避率 +2% | 3 |
| 星术 | 星脉回路 | 智力 +4，最大星界能量 +10 | 3 |
| 圣域 | 慈悲之心 | 决心 +4，生命增幅 +5% | 3 |

七项内容完全对称，各自是所属星轨冠位的低配版本。它们缺席的直接后果是：**每条星轨从第一层到冠位之间没有中间里程碑**，玩家在第 90 级拿到冠位之前，只能靠属性节点累积。

### 8.2 四对未放置的属性节点

盾势值回复速度、近战暴击伤害、隐蔽效能、魔法暴击伤害各有一对基础／强化节点已定义但未放置。其中盾势值回复速度与护盾强效只出现在冠位奖励里，隐蔽效能只出现在先见冠位里——三者目前都无法通过普通节点逐步投资。

## 9. 成长与平衡

- **上限即取舍。** 100 点对 764 点的比例意味着任何构筑都必然放弃大部分内容，因此技能树不需要额外的互斥规则来制造决策，稀缺本身就是决策。
- **一条星轨全通（97 点）是一个真实选项。** 它给出该方向的全部属性与一个冠位，代价是完全没有汇流与第二条星轨。这个上限值被刻意设在 100 点之内而非之外，是为了让“专精到底”成为可以真正达成的目标，而不是永远差一口气。
- **横向移动有明码标价。** 汇流节点 2 点、双资质各 +1，比同价位的单星轨节点略优，用来补偿绕路成本。
- **属性节点量级刻意压低。** 单点节点普遍是 +1 资质、+1%—+3% 属性，强化节点约为三倍。技能树负责提供构筑方向，不负责提供爆发性数值。
- **冠位是唯一的强力节点，且被三重约束**：8 点花费、90 级等级要求、同星轨二选一。
- **技能树不提供职业适性许可**，玩家不能靠点数解锁本职业没有的武器类别或施法资格。

## 10. UI、程序与本地化

- 技能树使用形状与颜色双重编码：金色六边形代表可习得能力，金色圆形代表进阶门与之召，银色圆形代表普通属性节点，银色六边形代表被动能力。锁定态使用同一图案的暗色版本，不只依赖色相区分。
- 连线颜色分为锁定、可用、已解锁、已排除四态，互斥的冠位连线使用「已排除」配色，让二选一的后果在点击前就可见。
- 分类描述必须保留“主动能力已完成实现骨架，但目前刻意不附带战斗效果”这句说明。在主动技能接入实际效果之前删除它，等同于对玩家隐瞒。
- 节点描述统一先写触发条件，再写效果、持续、冷却与例外。
- 进阶门节点复用属性节点的显示名与描述键，因此修改属性节点文本会同时改变七条星轨的进阶门文本。
