# 元素与术式技能系统

## 1. 玩家承诺与系统边界

十二系术式各自提供一种改变战场的语言，而不只是十二种颜色的伤害：

- 火、冰、雷、水、风、土是可与自然精魂共鸣的六元素；
- 灵魂、治愈、光、暗、奥秘、星界是复合对象与法则形成的六门高阶学科。

每系均包含入门攻击、位移或防守、状态互动、探索能力与高成本终极术。数值为首轮原型基线；资源键与技能功能定稿。世界内原理见[魔法系统背景](../Lore/Magic_System_Lore.md)。

## 2. 世界内解释

术式是施术者、魔导体、环境精魂与目标共同完成的一次法则协商。时钟塔把常见协商方式整理为十二系，公会再以这套分类登记导师和委托；民间仍会把同一术式称作不同名字。分类用于教学与实现，不意味着自然界真的存在十二只互不往来的“元素盒子”。

玩家学习一个术式时获得的是稳定公式、动作和反制知识。威力仍受环境、媒介、熟练度与目标状态影响；因此技能表给出稳定功能和边界，具体数值留给战斗原型。

## 3. 资源键与效果书写

下表使用键干，例如 `fire_fireball`：

- 显示名：`spellname.isekaiexpansion.fire_fireball`
- 描述：`spelldesc.isekaiexpansion.fire_fireball`

所有技能详情固定显示系别、位阶、MP 消耗档、吟唱 / 引导、冷却、状态与反制。表中“低 / 中 / 高 / 极高”先用于设计比较，具体 MP 随角色等级和装备换算，避免文档在基础资源尚未定稿时写死伪精确值。

## 4. 共通状态与交互

| 状态 | 基础效果 | 主要交互与反制 |
| --- | --- | --- |
| 燃烧 | 持续火伤 6 秒，可刷新不叠层 | 水与净化解除；寒冷降低持续时间 |
| 寒冷 | 移速 -10%，叠至 100 触发冻结 | 火降低积累；首领冻结转为短硬直 |
| 冻结 | 无法行动 2 秒，受碎冰效果加成 | 受重击后提前破碎；连续冻结递减 |
| 湿润 | 火伤 -20%，雷伤与麻痹积累 +25% | 火会消耗状态；土系可转泥泞 |
| 麻痹 | 攻速、施法速度 -15%，满积累硬直 | 绝缘、土系护盾与控制抗性 |
| 流血 | 移动或攻击时受到额外持续伤害 | 构装体免疫；包扎与治愈解除 |
| 致盲 | 锁定距离和远程命中下降 | 近战、声波索敌与光抗性 |
| 沉默 | 禁用需要咏唱的术式 | 武技、预编道具与无咏唱仍可用 |
| 恐惧 | 普通敌人远离来源，玩家操作受扰 | 首领转为攻击降低；精神净化 |
| 腐蚀 | 护甲降低，叠层有上限 | 清洗、修理与土系加固 |
| 静滞 | 无法行动也不受伤害 | 结束后 1 秒内免疫再次静滞 |

同类硬控制在 12 秒内重复命中会累积抗性。首领不免疫整套机制，而是把长控转为架势伤害、减速或可读的短硬直。

## 18. 成长、平衡、失败与滥用防护

- 每系入门术负责建立状态或空间优势，终极术负责兑现，不让低阶法术在后期完全失效。
- 同一角色可学习多系，但装备栏、专精加成与媒介调谐限制实战同时携带数量。
- 元素联动以可读状态为前提：湿润接雷、冻结后碎冰、暗影依赖光线。禁止隐藏乘区导致玩家无法理解伤害。
- 反射、免死、冷却重置、静滞和百分比伤害共享全局限制，不能通过多职业叠加无限循环。
- 探索术必须提供替代路径而非唯一门票。没有对应术式时，可通过道具、NPC、地形或更高成本解决。

## 19. UI、程序与本地化

- 状态图标显示来源、剩余时间、叠加与可净化性。
- 地面危险使用统一轮廓语言：友方细边、敌方实边、中立双边；不只依赖红绿区分。
- 技能描述先写结果，再写条件和代价。避免“毁灭性、绝对、无限”等无实现信息的形容。
- “复活术”玩家显示已定为“战地复苏”，资源键暂不改，避免与剧情死亡冲突。
- 光系不对所有魔族自动克制；克制对象是特定不死、影质与蚀理造物，避免把历史偏见写进底层数值。
